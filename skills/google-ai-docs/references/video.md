# Video generation in the Gemini API

Use [Gemini Omni Flash](/docs/omni) as your model for video generation and conversational
video editing in the Gemini API. It provides superior video coherence,
multi-input reasoning (supporting text, images, audio, and video inputs
simultaneously), character consistency, factual accuracy, and multi-turn
conversational editing (e.g., element replacement or perspective changes).

The Veo 3.1 Preview in the Gemini API has been shut down.

## Gemini Omni Flash  {% id="omni-flash" %}

Gemini Omni Flash is a fast, multimodal model for video generation and
conversational video editing. It excels at quickly turning text prompts and
images into short videos, and lets you refine results across multiple turns
using the Interactions API.

[Get started with Gemini Omni Flash →](/docs/omni)
