# Guides

Last updated Oct 19, 2026|Copy as Markdown| [View as Markdown](https://developers.cloudflare.com/cloudflare-one/cloud-workload-security/guides/index.md)| [Agent setup](https://developers.cloudflare.com/agent-setup/)

Use these guides to configure Cloud Workload Security resources:

- [Configure policies](https://developers.cloudflare.com/cloudflare-one/cloud-workload-security/guides/configure-policies/): define workloads, write policies, and attach policy sets to deployments.
- [Manage traffic scope](https://developers.cloudflare.com/cloudflare-one/cloud-workload-security/guides/manage-traffic-scope/): configure domain access control lists and manage Basic Auth secrets.
- [Manage policy reference resources](https://developers.cloudflare.com/cloudflare-one/cloud-workload-security/guides/policy-reference/): create reusable Rego modules, metadata, and tenant structures.

To understand how CWS validates requests, refer to [Request Validation](https://developers.cloudflare.com/cloudflare-one/cloud-workload-security/concepts/request-validation/). To connect your first proxy and test a policy, follow [Get started](https://developers.cloudflare.com/cloudflare-one/cloud-workload-security/get-started/).
