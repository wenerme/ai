#  Submission addresses

Last updated Apr 17, 2026 | Copy as Markdown | [ View as Markdown ](https://developers.cloudflare.com/cloudflare-one/email-security/settings/phish-submissions/submission-addresses/index.md) | [ Agent setup ](https://developers.cloudflare.com/agent-setup/)

To view the destination addresses of user and team submissions:

1. Log in to [Cloudflare One ↗](https://one.dash.cloudflare.com/).
2. Select **Email security**.
3. Select **Settings**.
4. Go to **Phish submission** \> **Submission addresses** \> **View**.

The dashboard will display **User submission addresses** and **Team submission addresses**.
