# Deactivate Connector

Last updated Apr 17, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-wan/configuration/appliance/maintenance/deactivate-appliance/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

1. Log in to [Cloudflare One](https://one.dash.cloudflare.com/), and go to **Networks**.
2. Go to **Connectors** \> **Appliances** \> **Appliances**.
3. Find the Cloudflare One Appliance you want to deactivate, select the three dots next to it > **Edit**.
1. In **Status**, select _Deactivated_ from the drop-down menu.
2. Select **Update**.
