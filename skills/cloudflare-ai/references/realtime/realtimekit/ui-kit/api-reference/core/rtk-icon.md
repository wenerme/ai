#  rtk-icon

Last updated Apr 21, 2026 | Copy as Markdown | [ View as Markdown ](https://developers.cloudflare.com/realtime/realtimekit/ui-kit/api-reference/core/rtk-icon/index.md) | [ Agent setup ](https://developers.cloudflare.com/agent-setup/)

An icon component which accepts an svg string and renders it.

## Properties

| Property | Type        | Required | Default | Description  |
| -------- | ----------- | -------- | ------- | ------------ |
| icon     | string      | ✅        | \-      | Icon         |
| size     | Size1       | ✅        | \-      | Size         |
| variant  | IconVariant | ✅        | \-      | Icon variant |

## Usage Examples

### Basic Usage

```html
<rtk-icon></rtk-icon>
```

### With Properties

```html
<rtk-icon
 icon="example"
 size="md"
 variant="primary">
</rtk-icon>
```

```html
<script>
  const el = document.querySelector("rtk-icon");

</script>
```
