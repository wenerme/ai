# rtk-emoji-picker

Last updated Apr 21, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/realtime/realtimekit/ui-kit/api-reference/angular/rtk-emoji-picker/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

A very simple emoji picker component.

## Properties

| Property        | Type     | Required | Default         | Description                               |
| --------------- | -------- | -------- | --------------- | ----------------------------------------- |
| focusWhenOpened | boolean  | ✅        | \-              | Controls whether or not to focus on mount |
| iconPack        | IconPack | ❌        | defaultIconPack | Icon pack                                 |
| t               | RtkI18n  | ❌        | useLanguage()   | Language                                  |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-emoji-picker></rtk-emoji-picker>
```

### With Properties

```html
<!-- component.html -->
<rtk-emoji-picker
 [focusWhenOpened]="true">
</rtk-emoji-picker>
```
