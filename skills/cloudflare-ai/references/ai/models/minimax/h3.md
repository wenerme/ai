# MiniMax H3

Text-to-Video • MiniMax

Copy as Markdown| [View as Markdown](https://developers.cloudflare.com/ai/models/minimax/h3/index.md)| [Agent setup](https://developers.cloudflare.com/agent-setup/)

`minimax/h3`

- Third-party

A multimodal video generation model supporting text-to-video, first and last frame image-to-video, and reference-to-video generation with 768P and 2K output.

## Usage

```ts
const response = await env.AI.run(
  'minimax/h3',
  {
    content: [
      {
        type: 'text',
        text: 'A cinematic space-opera teaser: a fleet jumps into hyperspace above a purple nebula while a lone captain watches from a glass observation deck.',
      },
    ],
    duration: 5,
    ratio: '16:9',
    resolution: '2K',
  },
)
console.log(response)
```

```bash
curl https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/ai/run \
  --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{
  "model": "minimax/h3",
  "input": {
    "content": [
      {
        "type": "text",
        "text": "A cinematic space-opera teaser: a fleet jumps into hyperspace above a purple nebula while a lone captain watches from a glass observation deck."
      }
    ],
    "duration": 5,
    "ratio": "16:9",
    "resolution": "2K"
  }
}'
```
