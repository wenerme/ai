# Code & reviews

Review GitHub pull requests and agent code diffs in Linear. Open [**Settings → Account → Code & reviews**](https://linear.app/settings/account/code-and-reviews) to configure these preferences.

## Code reviews

### Enable code reviews

Enable reviewing GitHub pull requests directly in Linear from the sidebar. Having the GitHub integration connected is a requirement.

### Review notifications

Choose which code review events you want to be notified about, All activity, All activity by people, Reviews and comments, Reviews and comments by people or none.

### Auto-convert draft pull requests

Automatically mark a draft pull request as ready when a review is requested or approved.

### Code theme & font

Select the syntax highlighting theme and font used in code diffs and viewers. You can choose the font family, size, and weight used when displaying code.

## External tools

### Configure coding tools

Choose the external coding tools in which you can open Linear issues, such as Claude, Codex desktop, Cursor and more. Prompt templates and default terminal apps can also be configured here.

### Git attachment format

Choose how GitHub and GitLab attachments are displayed on issues, Title, or Title+Repository.

### On git branch copy, move issue to started status

Automatically move an issue to the team's first started status after copying its Git branch name. Hold **Option** while copying to disable this behavior for that action.

### On open in coding tool, move issue to started status

Automatically move an issue to the team's first started status after opening it in a coding tool or copying it as a prompt. Hold **Option** to disable this behavior for that action.
