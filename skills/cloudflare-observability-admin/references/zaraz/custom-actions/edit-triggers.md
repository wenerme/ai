# Edit triggers

Last updated Apr 16, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/zaraz/custom-actions/edit-triggers/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

1. In the Cloudflare dashboard, go to the **Tag setup** page.
[Go to **Tag setup** ↗](https://dash.cloudflare.com/?to=/:account/tag-management/zaraz)
2. Go to **Tools Configuration**.
3. Under **Triggers**, locate your trigger and select **Edit**.

You can edit every field related to the trigger, as well as add new trigger rules.

## Delete a trigger

1. In the Cloudflare dashboard, go to the **Tag setup** page.
[Go to **Tag setup** ↗](https://dash.cloudflare.com/?to=/:account/tag-management/zaraz)
2. Go to **Tools Configuration**.
3. Under **Triggers**, locate your trigger and select **Delete**.
