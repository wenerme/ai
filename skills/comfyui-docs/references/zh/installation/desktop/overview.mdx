**Comfy Desktop** 是一个桌面应用，让你从一个启动器中安装、管理和启动多个 ComfyUI 实例。

[Desktop 截图]

## 工作原理

Comfy Desktop 将**启动器**与**工作流编辑器**分开。每个安装独立运行自己的 ComfyUI 后端，拥有自己的 Python 环境、自定义节点和设置。启动一个安装时，它会在独立的窗口中打开完整的 ComfyUI 编辑器。

```mermaid
flowchart LR
    A[Comfy Desktop 启动器] --> B[安装 1<br/>最新版]
    A --> C[安装 2<br/>v0.2.4]
    B --> F[ComfyUI 编辑窗口]
    C --> G[ComfyUI 编辑窗口]
```

Comfy Desktop 支持 **Windows 10+**、**macOS 13+（Apple Silicon）** 和 **基于 Debian 的 Linux**。每个独立安装需要至少 **4.85 GB** 磁盘空间和 **8 GB 内存（推荐 16 GB）**。详细要求请查看各平台安装页面。

## 开始使用

选择你的平台开始：

  
    Windows 10 或更新版本的安装指南。
  

  
    macOS 13+（Apple Silicon）的安装指南。
  

  
    基于 Debian 的发行版的安装指南。
  

## 使用指南

安装完成后，了解如何使用 Comfy Desktop：

  
    创建、重命名、编辑和删除 ComfyUI 实例。
  
  
    启动、更新、快照和配置你的安装。
  
  
    全局设置、代理/镜像、快捷键和数据位置。
  
  
    从 Desktop Legacy 升级——自定义节点和工作流都会携带过来。
  

## 开源

Comfy Desktop 完全开源。在 [GitHub](https://github.com/Comfy-Org/Comfy-Desktop) 上查看源代码。
