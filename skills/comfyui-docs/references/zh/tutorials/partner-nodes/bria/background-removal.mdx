Bria 的 AI 背景处理模型现已通过合作节点在 ComfyUI 中提供。本页涵盖**图像背景移除**、**引导式图像背景移除**、**视频背景移除**、**透明视频背景**、**视频绿幕**和**视频背景替换**。

## Bria 背景移除擅长什么

- **图像背景移除**：自动移除图像背景，并以透明背景返回结果
- **引导式图像背景移除**：只保留提示词描述的主体并移除其余内容，因此可以从复杂场景中单独抠出一个主体，而不是保留所有非背景内容
- **视频背景移除**：将视频背景替换为您选择的纯色，或输出带透明度的视频
- **视频绿幕**：应用专业的色度键绿幕或蓝幕效果，预设包括 broadcast_green、chroma_green 和 blue_screen
- **视频背景替换**：将视频背景替换为自定义图像或另一段视频
- **短视频支持**：视频背景处理支持最长 60 秒的输入视频

### Bria：引导式移除背景 {#api_bria_guided_remove_background}

在保留提示词所描述内容的前提下移除图像背景。该节点不会保留所有非背景内容，而是把抠图收窄到你指定的主体，这正是从复杂场景中干净分离出一个人或物体的方式。原始像素会以完整分辨率返回，并附带新的 alpha 通道。

[Bria：引导式移除背景工作流预览]

  
    在 Comfy Cloud 中打开
  
  
    下载 JSON，或在模板库中搜索 &quot;Bria: Guided Background Removal&quot;
  

**输入素材**

将此文件上传到对应的 `LoadImage` 节点：

  加载到 `LoadImage` 节点

`prompt` 用于指定要保留的内容，例如 `the man in the blue shirt` 或 `only the shoes`。如果提示词没有匹配任何内容，会返回完全透明的图像。开启 `moderation` 会显示独立的视觉输入与输出审核开关；关闭则跳过。若只需不带引导的普通抠图，请使用上文的 **Bria：移除图像背景**。
