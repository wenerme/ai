Topaz 图像增强 Wonder 3.5 是一款生成式增强模型，可通过 Topaz 合作节点在 ComfyUI 中使用。它能够添加精细细节、降低噪波，并锐化文本和结构化图形，提供低、中、高三档增强强度。该模型会保留输入的长宽比，并支持从 1x 至 6x 的放大倍数。

## Topaz Image Enhance Wonder 3.5 擅长什么

- **生成式细节还原**：为来源图像添加精细细节
- **降噪**：在增强的同时去除噪波
- **文本和图形锐化**：锐化文本和结构化图形
- **可调强度**：可选择低、中、高增强强度
- **灵活的输出**：保留输入图像的宽高比，支持 1x 至 6x 的放大倍数

## Topaz 图像增强 Wonder 3.5

### 工作流总览

该工作流使用以下四个节点：

- **LoadImage**：提供来源图像
- **TopazImageEnhanceV2**：核心节点，配置为使用 `Wonder 3.5` 增强模型
- **SaveImageAdvanced**：将增强后的输出保存为 PNG
- **ImageCompare**：将增强结果与原始图像并排显示，方便对比

### 运行步骤

1. **加载图像**：在 **LoadImage** 节点中上传或选择您的输入图像
2. **选择模型**：在 **TopazImageEnhanceV2** 节点上保持 `Wonder 3.5` 不变
3. **选择增强强度**：`low`、`medium` 或 `high`
4. **设置放大倍数**：从 1x 到 6x
5. **点击“队列”按钮**：按 `Ctrl+Enter` 开始生成
