## 使用图像模型可以做什么

- **文生图**：根据文本提示词生成图像
- **图像编辑**：修改现有图像，更改内容、重设风格或参照参考图
- **图生图**：变换输入图像以生成新版本，同时保持其结构
- **图像放大与增强**：提高分辨率或提升质量
- **实用工作流**：背景移除、重新布光等

## 按任务选择模型

### 通用文生图

如果您希望通过简单的文本提示获得最佳整体质量，可从以下模型入手：

- **Flux.1 Kontext**（Black Forest Labs）：具备最先进的生成能力，对提示词的遵循度很高；支持多张输入图像，可进行上下文感知编辑
- **Flux 1.1 Pro Ultra**（Black Forest Labs）：Flux 家族中的高端生成模型
- **GPT-Image-2 / GPT-Image-1**（OpenAI）：通过单一 API 提供强大的文生图与图像编辑功能
- **Qwen Image 3.0 Pro**（Qwen 千问）：阿里巴巴 Qwen 千问系列中快速、高质量的生成模型

### 图像编辑与 Inpainting

这些模型专为修改现有图像而设计：

- **Nano Banana Pro / Nano Banana 2 / Nano Banana 2 Lite**（Google）：Google 基于 Gemini 的图像编辑与生成模型，非常适合在对话中进行后续编辑
- **Luma Uni-1**（Luma）：通过自然语言指令创建和修改图像
- **Muse Image 1.0**（Meta）：基于指令的图像编辑，单次可融合最多 10 张参考图
- **Ideogram 4.0**（Ideogram）：擅长在图像中渲染文字；支持以图像输入进行编辑

### 背景移除与实用工具

- **Bria Background Removal**（Bria）：干净地移除图像背景
- **Bria Fibo / Bria Image Editing**（Bria）：编辑与修复实用工具
- **Topaz Image Enhance Wonder 3.5 / Bloom 2**（Topaz）：支持 upscale 与图像质量恢复

### 速度与性价比

- **Nano Banana 2 Lite**（Google）：Nano Banana 系列中更轻量、更快速的变体
- **Recraft V4 / Recraft Text-to-Image**（Recraft）：面向设计的生成，支持风格控制
- **Seedream 5.0 Pro / Lite**（字节跳动）：字节跳动推出的快速生成模型
