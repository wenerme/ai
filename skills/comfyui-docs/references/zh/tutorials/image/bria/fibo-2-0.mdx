FIBO 2.0 是 Bria 的 8B 图像模型，用同一套权重完成生成与编辑。开放权重版本在 ComfyUI 本地运行，不消耗积分；它工作在 FLUX.2 VAE 的 Latent 空间，提示词由 Qwen3-VL-4B 编码。

它附带两个模板。**Fibo 2.0 Turbo：图像编辑** 是蒸馏版本，适合快速试方向；**Fibo 2.0 Dev：图像编辑** 运行未蒸馏的基础模型，编辑结果最干净。两者都接收一张参考图像和一句指令。

## 模型下载

两个模板都加载 int8_convrot 文件、bf16 的 4B 文本编码器，以及提示词增强器读取参考图像所用的 8B 编码器。bf16 扩散模型是同一套权重的完整精度版本，体积约为两倍。

  
    fibo2_edit_turbo_int8_convrot.safetensors &#8594; ComfyUI/models/diffusion_models/
  
  
    fibo2_dev_int8_convrot.safetensors &#8594; ComfyUI/models/diffusion_models/
  
  
    fibo2_edit_turbo_bf16.safetensors &#8594; ComfyUI/models/diffusion_models/
