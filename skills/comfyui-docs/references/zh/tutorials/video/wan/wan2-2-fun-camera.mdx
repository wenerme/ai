**Wan2.2-Fun-Camera-Control** 是 Alibaba PAI 团队推出的新一代视频生成与相机控制模型，通过引入创新性的相机控制代码（Camera Control Codes）机制，结合深度学习和多模态条件输入，能够生成高质量且符合预设相机运动条件的视频。该模型采用 **Apache 2.0 许可证**发布，支持商业使用。

**核心功能**：
- **相机运动控制**：支持多种相机运动模式，包括 **Pan Up（向上平移）**、**Pan Down（向下平移）**、**Pan Left（向左平移）**、**Pan Right（向右平移）**、**Zoom In（放大）**、**Zoom Out（缩小）** 等，以及组合运动。
- **高质量视频生成**：基于 Wan2.2 架构，输出影视级视频。

下面是相关模型权重和代码仓库：

- [🤗Wan2.2-Fun-A14B-Control-Camera](https://huggingface.co/alibaba-pai/Wan2.2-Fun-A14B-Control-Camera)
- 代码仓库：[VideoX-Fun](https://github.com/aigc-apps/VideoX-Fun)

## Wan2.2 Fun Camera Control：视频生成工作流示例

这里提供的工作流包含两个版本：
1. 使用了 lightx2v 的 [Wan2.2-Lightning](https://huggingface.co/lightx2v/Wan2.2-Lightning) 4 步 LoRA：这可能会降低视频的动态效果，但生成速度更快。
2. 未使用加速 LoRA 的 fp8_scaled 版本。

下面是在 RTX4090D 24GB 显存 GPU 上，640×640 分辨率、81 帧长度的测试结果：

| 模型类型                 | 分辨率  | 显存占用 | 首次生成时长 | 第二次生成时长 |
| ------------------------ | ------- | -------- | ------------ | -------------- |
| fp8_scaled               | 640×640 | 84%      | ≈ 536 秒     | ≈ 513 秒       |
| fp8_scaled + 4 步 LoRA   | 640×640 | 89%      | ≈ 108 秒     | ≈ 71 秒        |

4 步 LoRA 可改善初次使用的体验，但可能会降低视频的动态效果。默认启用了加速 LoRA 版本。如需切换工作流，框选节点后按 **Ctrl+B**。

### 3. 按步骤完成工作流

[Wan2.2 Fun Camera Control 工作流步骤]

  本工作流使用了 LoRA。请确保扩散模型与 LoRA 一致；高噪声和低噪声模型及 LoRA 需对应使用。

1. **高噪声**模型及 **LoRA** 加载
   - 确保 `Load Diffusion Model` 节点加载了 `wan2.2_fun_camera_high_noise_14B_fp8_scaled.safetensors`
   - 确保 `LoraLoaderModelOnly` 节点加载了 `wan2.2_i2v_lightx2v_4steps_lora_v1_high_noise.safetensors`
2. **低噪声**模型及 **LoRA** 加载
   - 确保 `Load Diffusion Model` 节点加载了 `wan2.2_fun_camera_low_noise_14B_fp8_scaled.safetensors`
   - 确保 `LoraLoaderModelOnly` 节点加载了 `wan2.2_i2v_lightx2v_4steps_lora_v1_low_noise.safetensors`
3. 确保 `Load CLIP` 节点加载了 `umt5_xxl_fp8_e4m3fn_scaled.safetensors`
4. 确保 `Load VAE` 节点加载了 `wan_2.1_vae.safetensors`
5. 在 `Load Image` 节点上传起始帧
6. 修改 Prompt（中文或英文均可）
7. 在 `WanCameraEmbedding` 节点设置相机控制参数：
   - **Camera Motion**：选择相机运动类型（Zoom In、Zoom Out、Pan Up、Pan Down、Pan Left、Pan Right、Static 等）
   - **Width/Height**：设置视频分辨率
   - **Length**：设置视频帧数（默认 81 帧）
   - **Speed**：设置视频速度（默认 1.0）
8. 点击 `Run` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 来执行视频生成
