Marigold V2 是华为拜耳实验室推出的一系列单目估计模型，该系列将扩散 transformer（Qwen-Image Edit 2509）重新用于几何与固有图像估计。仅凭一张 RGB 图像，这些模型就能预测深度图、表面法线或反照率，延续了原始的 Marigold（CVPR 2024，同样将 Stable Diffusion 用于该任务）的思路。V2 系列模型以 LoRA 的形式发布在一个共享的基础扩散模型之上，因此每个文件的下载体积都很小，并且三项使用例的工作流结构完全一致。

与经典深度网络相比，这种基于扩散的方法能生成锐利且边界感知良好的预测结果，并且无需重新训练即可泛化到开放域图像。典型用途包括图像与视频生成中的深度引导控制、3D 场景重建流水线、重打光，以及由估计出的反照率驱动的材质编辑。

Marigold V2 已在 ComfyUI 中原生支持。开始之前，请先将 [ComfyUI](https://github.com/comfyanonymous/ComfyUI) 更新到最新版本。

## 模型安装

每个工作流使用四个文件：共享的基础 diffusion 模型，以及特定任务的 LoRA、VAE 和条件 embedding。三个任务使用不同的 LoRA、VAE 和条件文件，因此下面的每个工作流章节都链接了它所需的确切文件。

基础 diffusion 模型由三个工作流共享：

  qwen_image_edit_2509_int8_convrot.safetensors &#8594; ComfyUI/models/diffusion_models/

如果你打算运行全部三个任务，请从各工作流章节下载对应的 LoRA、VAE 和条件 embedding，并按照每个章节所示的位置存放它们。

## 深度估计 {#image_marigold_v2_depth_estimation}

从单张图像预测深度图。解码后的预测结果会被归一化，使距离较近的表面显得更亮。

[Marigold V2 深度估计工作流预览]

  
    在 Comfy Cloud 中打开
  
  
    下载 JSON，或在模板库中搜索 &quot;深度估计：Marigold V2&quot; 
  

**输入素材**

将该文件上传到对应的 `LoadImage` 节点:

  
    `LoadImage` 节点 · `ev_suv_gold_desert_pavilion.png`
  

### 1. 运行步骤

1. 在 `LoadImage` 节点中加载输入图像
2. 运行工作流：基础模型会加载深度 LoRA，Marigold V2 Post-Process 节点会将解码后的预测归一化
3. 保存或预览生成的深度图

### 2. 模型下载

## Marigold V2 后处理节点

每个工作流都以 **Marigold V2 Post-Process** 节点结尾，该节点会将解码后的原始预测转换为可查看的图像。**prediction** 选项必须与任务匹配：

- **depth**：对预测进行归一化，使靠近的表面显得明亮
- **normals**：将原始值映射为单位表面法线
- **albedo**：将预测转换为 sRGB
