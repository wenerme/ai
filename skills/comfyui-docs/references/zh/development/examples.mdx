## 在 Comfy Cloud 上自定义 Build

将你自己的 ComfyUI 工作流打包为自定义 Build，部署到 Comfy Cloud，并从你的代码中调用它。

  
    创建 Build、发布它，并启动托管部署。
  
  
    在部署之前查找可用的区域和 GPU 类型。
  
  
    提交 API 格式的工作流并下载其输出。
  
  
    将 Python 或 TypeScript SDK 指向你的部署。
