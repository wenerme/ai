## Comfy API

打包你自己的 ComfyUI 工作流，将其部署到托管的 GPU 基础设施，并通过 Comfy API 运行。

  
    创建 Build、发布它，并启动托管部署。
  
  
    在部署之前查找可用的区域和 GPU 类型。
  
  
    提交 API 格式的工作流并下载其输出。
  
  
    将 Python 或 TypeScript SDK 指向你的部署。
