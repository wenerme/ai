## 模型 API

使用 Comfy Router，仅凭一个 Comfy API 密钥即可调用托管的合作伙伴模型。

  
    用 Python、TypeScript 或 cURL 配合 Flux 生成你的第一张图像。
  
  
    查找模型、查看其输入，并复制其模型 ID。
  
  
    查看某个 Router 模型的请求和响应结构。
  
  
    查阅 Router 的公共端点和请求头。
  

## Comfy API

打包你自己的 ComfyUI 工作流，将其部署到托管的 GPU 基础设施，并通过 Comfy API 运行。

  
    创建一个 Build、发布它，然后启动托管部署。
  
  
    在部署之前，先了解可用的区域和 GPU 类别。
  
  
    提交 API 格式的工作流并下载其输出。
  
  
    将 Python 或 TypeScript SDK 指向你的部署。
