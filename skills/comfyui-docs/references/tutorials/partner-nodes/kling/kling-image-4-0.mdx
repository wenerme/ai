Kling Image 4.0 is Kling AI's image model, available in ComfyUI as Partner Nodes. `Kling 4.0 Image` renders stills up to 8K from a prompt, with up to ten reference images and an optional set of related variations. `Kling 4.0 Long Image` renders one tall page for a website or a product listing.

Three templates cover the workflows below.

## Kling 4.0: Text to Image {#api_kling4_image_t2i}

Renders one image from a prompt at 2K, 4K, or 8K, in eight aspect ratios or `auto` to follow the reference images. Connect up to ten reference images and name them in the prompt as `@Image1` onward to steer the result. Set `series_amount` to `auto` or a number from 2 to 10 to get a set of related images that keep the same characters and style.

## Kling 4.0: Image Edit {#api_kling4_image_edit}

Restyles an image while keeping what must not change. Connect the photo as the first reference image, then describe both the change and what stays: the template keeps the face, the framing, and the backdrop, and changes only the hair, makeup, and outfit. The node is the same as Text to Image, with a reference image connected.

## Kling 4.0: Long Image {#api_kling4_long_image}

Renders one very tall image in a single pass. Pick the kind of page with `skill`:

- `webpage`: optional style and subject images, addressed as `@Image1` and `@Image2`. Describe the page band by band, and state the language of the visible copy.
- `ecommerce`: one to three product images, addressed as `@Image1` onward, and a `length` of `short`, `medium`, or `long`.

Both skills render at 1K or 2K.

## Input limits

- Images: at least 300 x 300 px, aspect ratio between 2:5 and 5:2. `Kling 4.0 Image` takes up to ten reference images, and `Kling 4.0 Long Image` takes one to three product images in `ecommerce` mode.
- In the image nodes, a prompt that names `@ImageN` beyond the number of connected inputs fails the run. In the `webpage` skill, `@Image1` is `style_image` and `@Image2` is `subject_image`, so `@Image2` still works when only the subject image is connected.
