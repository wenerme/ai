## Acerca de texto a imagen

Texto a imagen es una función básica de generación con IA que crea imágenes a partir de descripciones de texto. Es una de las funciones más usadas en el arte con IA. Puedes imaginar el proceso como explicarle tus requisitos (prompts positivos y negativos) a un artista (el modelo), que luego crea lo que pediste. Encontrarás más detalle en el capítulo [Texto a imagen](/tutorials/basic/text-to-image).

## Tutorial del flujo de trabajo de texto a imagen de ComfyUI

### 1. Inicia ComfyUI

Asegúrate de haber seguido la [guía de instalación](/es/installation/system_requirements) para iniciar ComfyUI y abrir correctamente la interfaz. Como alternativa, puedes usar [Comfy Cloud](/es/get_started/cloud) para usar ComfyUI sin instalar nada.

[Interfaz de ComfyUI]

Si aún no tienes ComfyUI instalado, elige la versión adecuada para tu dispositivo.

### 2. Carga el flujo de trabajo predeterminado de texto a imagen

Por lo general, ComfyUI carga automáticamente el flujo de trabajo predeterminado de texto a imagen al iniciarse. Aun así, conviene probar distintos métodos de carga para familiarizarte con las operaciones básicas:

  
  Todas las imágenes generadas por ComfyUI contienen metadatos, incluida la información del flujo de trabajo. Puedes cargar flujos de trabajo de las siguientes maneras:
  - Arrastrando y soltando en la interfaz una imagen generada por ComfyUI
  - Usando el menú **Workflows** -> **Open** para abrir una imagen

  Prueba a cargar el flujo de trabajo usando esta imagen de ejemplo:
  ![Flujo de trabajo Texto a imagen de ComfyUI](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/text-to-image-workflow.png)

  
  Los flujos de trabajo de ComfyUI se pueden almacenar en formato JSON. Puedes exportar flujos de trabajo usando el menú **Workflows** -> **Export**.

### 4. Cargar el modelo y generar tu primera imagen

Después de instalar o actualizar modelos, pulsa **`R`** para refrescar las definiciones de objetos y las listas de modelos en los nodos (por ejemplo, el menú desplegable de **Load Checkpoint**). Luego sigue estos pasos:

[Ejecutar flujo de trabajo]
1. En el nodo **Load Checkpoint**, asegúrate de que **v1-5-pruned-emaonly-fp16.safetensors** esté seleccionado
2. Haz clic en `Run` o presiona `Ctrl + Enter` para generar

El resultado aparecerá en el nodo **Save Image**. Haz clic derecho para guardarlo localmente.

## Solución de problemas

### Problemas al cargar modelos

Si el nodo `Load Checkpoint` no muestra ningún modelo o aparece como "null", comprueba dónde instalaste los modelos e intenta refrescar o reiniciar ComfyUI.
