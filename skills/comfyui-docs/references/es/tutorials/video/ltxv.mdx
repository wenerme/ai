[LTX-Video](https://huggingface.co/Lightricks/LTX-Video) es un modelo de video muy eficiente de Lightricks. Lo importante con este modelo es darle prompts largos y descriptivos.

Te permite controlar el video con una serie de imágenes. Puedes descargar las imágenes de entrada: [fotograma inicial](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/ltxv/multi-frame/house1.png) y [fotograma final](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/ltxv/multi-frame/house2.png).

  Descarga y guárdalo en ComfyUI/models/text_encoders/

```
├── checkpoints/
│   └── ltx-video-2b-v0.9.5.safetensors
```
