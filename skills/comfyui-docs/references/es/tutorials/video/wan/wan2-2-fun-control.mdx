**Wan2.2-Fun-Control** es un modelo de generación y control de video de nueva generación lanzado por el equipo de Alibaba PAI. Gracias a un innovador mecanismo de Control Codes combinado con aprendizaje profundo y entradas condicionales multimodales, puede generar videos de alta calidad que respetan las condiciones de control predefinidas. El modelo se publica bajo la **licencia Apache 2.0** y admite uso comercial.

**Características principales**:
- **Control multimodal**: admite varias condiciones de control, como **Canny (arte lineal)**, **Profundidad**, **OpenPose (pose humana)**, **MLSD (bordes geométricos)** y **control de trayectoria**
- **Generación de video de alta calidad**: basado en la arquitectura Wan2.2, produce videos con calidad cinematográfica
- **Compatibilidad con varios idiomas**: admite prompts en varios idiomas, incluidos el chino y el inglés

A continuación, los pesos del modelo y los repositorios de código relevantes:

- [🤗Wan2.2-Fun-A14B-Control](https://huggingface.co/alibaba-pai/Wan2.2-Fun-A14B-Control)
- Repositorio de código: [VideoX-Fun](https://github.com/aigc-apps/VideoX-Fun)

## Ejemplo de flujo de trabajo de generación de video con Wan2.2 Fun Control

Este flujo de trabajo ofrece dos versiones:
1. Una versión que usa el LoRA de 4 pasos de [Wan2.2-Lightning](https://huggingface.co/lightx2v/Wan2.2-Lightning) de lightx2v: puede causar cierta pérdida en el dinamismo del video, pero ofrece mayor velocidad
2. Una versión fp8_scaled sin LoRA de aceleración

Estos son los resultados de las pruebas con una GPU RTX4090D de 24 GB de VRAM a una resolución de 640×640 con 81 fotogramas:

| Tipo de modelo           | Uso de VRAM | Tiempo de primera generación | Tiempo de segunda generación |
| ------------------------ | ----------- | ---------------------------- | ---------------------------- |
| fp8_scaled               | 83%         | ≈ 524s                       | ≈ 520s                       |
| fp8_scaled + LoRA de 4 pasos | 89%     | ≈ 138s                       | ≈ 79s                        |

Como el LoRA de 4 pasos ofrece una mejor experiencia a quienes usan el flujo de trabajo por primera vez, pero puede causar cierta pérdida en el dinamismo del video, hemos habilitado la versión con LoRA de aceleración de forma predeterminada. Si quieres habilitar el otro flujo de trabajo, selecciónalo y usa **Ctrl+B** para activarlo.

### 3. Guía del flujo de trabajo

[Pasos del flujo de trabajo de Wan2.2 Fun Control]

  Este flujo de trabajo usa LoRA. Asegúrate de que el modelo de difusión y la LoRA correspondientes coincidan: los modelos y las LoRA de ruido alto y ruido bajo deben usarse de forma correspondiente.

1. Carga del modelo de **ruido alto** y de la **LoRA**
   - Asegúrate de que el nodo `Load Diffusion Model` cargue el modelo `wan2.2_fun_control_high_noise_14B_fp8_scaled.safetensors`
   - Asegúrate de que el nodo `LoraLoaderModelOnly` cargue `wan2.2_i2v_lightx2v_4steps_lora_v1_high_noise.safetensors`
2. Carga del modelo de **ruido bajo** y de la **LoRA**
   - Asegúrate de que el nodo `Load Diffusion Model` cargue el modelo `wan2.2_fun_control_low_noise_14B_fp8_scaled.safetensors`
   - Asegúrate de que el nodo `LoraLoaderModelOnly` cargue `wan2.2_i2v_lightx2v_4steps_lora_v1_low_noise.safetensors`
3. Asegúrate de que el nodo `Load CLIP` cargue el modelo `umt5_xxl_fp8_e4m3fn_scaled.safetensors`
4. Asegúrate de que el nodo `Load VAE` cargue el modelo `wan_2.1_vae.safetensors`
5. Sube el fotograma inicial en el nodo `Load Image`
6. En el segundo nodo `Load video`, carga el video de control de pose. El video proporcionado ya está preprocesado y puedes usarlo directamente
7. Dado que proporcionamos un video de pose preprocesado, debes deshabilitar el nodo correspondiente de preprocesamiento de imágenes de video. Puedes seleccionarlo y usar `Ctrl + B` para deshabilitarlo
8. Modifica el prompt: puedes usar tanto chino como inglés
9. En `Wan22FunControlToVideo`, modifica las dimensiones del video. La resolución predeterminada es de 640×640 para evitar tiempos de procesamiento excesivos en usuarios con poca VRAM
10. Haz clic en el botón `Run` o usa el atajo `Ctrl(cmd) + Enter` para ejecutar la generación de video

### Notas adicionales

Como los nodos integrados de ComfyUI solo incluyen el preprocesador Canny, puedes usar herramientas como [ComfyUI-comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux) para implementar otros tipos de preprocesamiento de imágenes.
