**Mage-Flow** es un stack generativo compacto de escala 4B de Microsoft Research para la generación eficiente de imágenes a partir de texto y la edición de imágenes basada en instrucciones. El stack se construye a partir de dos componentes codiseñados: [Mage-VAE](https://huggingface.co/microsoft/Mage-VAE), un tokenizer latente ligero de alta fidelidad, y un Native-Resolution Multimodal Diffusion Transformer (NR-MMDiT) entrenado con rectified flow matching. Junto con el empaquetado a resolución nativa, este stack compartido impulsa dos instancias del modelo: Mage-Flow para texto a imagen y Mage-Flow-Edit para la edición de imágenes basada en instrucciones. Cada una se distribuye en variantes Base, alineada con RL y Turbo de 4 pasos.

Mage-Flow admite resoluciones nativas de 512 a 2048 píxeles por lado en cualquier relación de aspecto, incluidas dimensiones extremas como 4:1.

El flujo de trabajo se organiza en varias partes:

1. **Subgraph de texto a imagen (Mage-Flow)**: el pipeline de generación principal, que contiene la carga del modelo, el manejo del prompt, la generación de latentes en resolución nativa, el muestreo y la decodificación VAE
2. **SaveImageAdvanced**: guarda la imagen generada

  Este flujo de trabajo usa nodos Subgraph para el procesamiento modular. Consulta la documentación de Subgraph para aprender a personalizar y ampliar el flujo de trabajo.

### Generación con un clic

En el caso más simple, solo escribe un prompt de texto en el subgrafo, define la resolución que quieras y haz clic en **Queue Prompt**. Los valores predeterminados producen una imagen de alta calidad con una configuración mínima.

### Usar el flujo de trabajo

1. **Escribe un prompt**: escribe una descripción de texto en la entrada de prompt del subgrafo
2. **Define la resolución**: ajusta el ancho y el alto según el tamaño de salida que quieras. Mage-Flow admite resoluciones nativas de 512 a 2048 píxeles por lado.
3. **Ajusta las configuraciones**: configura la semilla y el prompt negativo según sea necesario
4. **Haz clic en Queue**: presiona `Ctrl+Enter` para generar

## Flujo de trabajo de edición de imágenes Mage-Flow-Edit

    Descarga el JSON o busca "Mage-Flow-Edit" en la biblioteca de plantillas
  
  
    Obtén la imagen de entrada de ejemplo para este flujo de trabajo
  

El flujo de trabajo de edición de imágenes usa Mage-Flow-Edit, un modelo basado en instrucciones que edita imágenes a partir de descripciones en lenguaje natural. Sube una o más imágenes de referencia y describe la edición que deseas.

El flujo de trabajo se organiza en varias partes:

1. **LoadImage**: sube tus imágenes de referencia (hasta 3)
2. **Subgrafo Image Edit (Mage-Flow-Edit)**: el pipeline principal de edición que contiene la carga del modelo, el acondicionamiento de las imágenes de referencia, el manejo del prompt y el muestreo
3. **ImageCompare**: una comparación lado a lado de la imagen original y la editada
4. **SaveImage**: guarda el resultado editado

### Usar la edición de imágenes

1. **Sube las imágenes de referencia**: usa el nodo **LoadImage** para cargar la imagen que quieres editar (hasta 3 imágenes)
2. **Escribe tu instrucción de edición**: introduce una descripción de texto de la edición que quieres aplicar (por ejemplo, "reemplaza el fondo con una escena de playa" o "convierte esto en una pintura a la acuarela")
3. **Ajusta las configuraciones**: configura la resolución, la semilla y otros parámetros
4. **Haz clic en Queue**: presiona `Ctrl+Enter` para generar

### Descargas de modelos

Para uso local, descarga los archivos de modelo optimizados para ComfyUI desde [Comfy-Org/Mage-Flow](https://huggingface.co/Comfy-Org/Mage-Flow).

  
    qwen3vl_4b_bf16.safetensors: codificador de texto Qwen3VL-4B
  
  
    mage_flow_vae_bf16.safetensors
  
  
    mage_flow_int8_convrot.safetensors: modelo base usado en el flujo de trabajo de texto a imagen
  
  
    mage_flow_turbo_int8_convrot.safetensors: modelo Turbo usado en el flujo de trabajo de texto a imagen Turbo
  
  
    mage_flow_edit_int8_convrot.safetensors: modelo Edit usado en el flujo de trabajo de edición
  
  
    mage_flow_edit_turbo_int8_convrot.safetensors: modelo Edit Turbo usado en el flujo de trabajo de edición Turbo
  

También hay otras variantes del modelo (BF16, FP8) para usuarios con configuraciones de hardware distintas.

Coloca los archivos en los siguientes directorios:
