Grok Imagine Image es el modelo de generación de imágenes de xAI, disponible en ComfyUI a través de los Nodos asociados de Grok. Genera imágenes a partir de prompts de texto y edita imágenes subidas con instrucciones en lenguaje natural, con compatibilidad para 13 relaciones de aspecto y salida de 1K o 2K.

## En qué destaca Grok Imagine Image

- **Generación de texto a imagen**: crea imágenes individuales a partir de un prompt de texto que describe la escena y el estilo
- **Edición de imágenes con lenguaje natural**: edita una imagen que subas según tu prompt, manteniendo la composición original y cambiando la escena, la iluminación o el estilo
- **Proporciones de aspecto flexibles**: admite 13 relaciones de aspecto, incluidas `1:1`, `16:9` y `9:16`
- **Opciones de resolución**: genera salidas en 1K o 2K

## Grok: Texto a imagen

Genera imágenes a partir de un prompt de texto con el modelo estándar `grok-imagine-image`. Este flujo de trabajo es la forma más rápida de crear imágenes individuales en ComfyUI con Grok, y admite 13 relaciones de aspecto y salida en 1K o 2K.

![Resultado de texto a imagen de Grok](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/output/api_grok_text_to_image.png)

### Resumen del flujo de trabajo

Este flujo de trabajo usa dos nodos:

- **GrokImageNode**: el nodo principal, configurado con el modelo `grok-imagine-image`
- **SaveImage**: guarda la imagen generada

### Pasos para ejecutar

1. **Introduce tu prompt**: describe la escena y el estilo en el nodo **GrokImageNode**
2. **Elige la relación de aspecto**: escoge entre relaciones como `1:1`, `16:9`, `9:16` y más
3. **Establece la resolución**: `1K` o `2K`
4. **Haz clic en Queue**: presiona `Ctrl+Enter` para generar

### Resumen del flujo de trabajo

Este flujo de trabajo usa tres nodos:

- **LoadImage**: proporciona la imagen de origen que se va a editar
- **GrokImageEditNode**: el nodo principal, configurado con el modelo `grok-imagine-image`
- **SaveImage**: guarda la imagen editada

### Pasos para ejecutar

1. **Carga una imagen**: conecta tu imagen al nodo **LoadImage**
2. **Describe la edición**: indica al modelo qué cambiar en el prompt del nodo **GrokImageEditNode**
3. **Haz clic en Queue**: presiona `Ctrl+Enter` para generar
