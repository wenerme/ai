La API pública para ejecutar ComfyUI sin interfaz ha evolucionado con el tiempo. Para nuevas integraciones, usa [Comfy API v2](/es/api-reference/v2/overview). Es compatible con ComfyUI de código abierto a través del [API Proxy](/es/development/comfyui-server/api-proxy), Comfy Cloud y las [implementaciones de Comfy API en la Developer Platform](/es/development/serverless/overview). Las versiones anteriores incluyen la [API v1 de Cloud](/es/development/cloud/overview), que está obsoleta.

  
    La API HTTP versionada para ejecutar flujos de trabajo desde cualquier lenguaje, en cualquier entorno. Empieza aquí.
  
  
    La API de Comfy Cloud anterior, que sigue disponible para integraciones existentes.
