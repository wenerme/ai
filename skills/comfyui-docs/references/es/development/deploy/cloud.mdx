Comfy Cloud es un entorno de ComfyUI totalmente administrado y siempre disponible. Crea flujos de trabajo en el navegador o ejecútalos mediante el SDK. No hay ningún Build ni despliegue que crear.

  ¿Es tu primera vez con Comfy Cloud? Empieza con la [introducción a Comfy Cloud](/es/get_started/cloud). Este inicio rápido muestra cómo ejecutar flujos de trabajo desde una aplicación.

## Inicio rápido

Requiere una suscripción de pago, una [clave API](/es/development/api-development/getting-an-api-key) y un flujo de trabajo en formato API. Los [SDK de Comfy](/es/development/api-development/sdks) apuntan a Cloud de forma predeterminada.

  
    Crea una clave API en [platform.comfy.org](https://platform.comfy.org). Consulta [Obtener una clave API](/es/development/api-development/getting-an-api-key) para más detalles.
  
  
    
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    
  
  
    En el editor de Cloud, guarda tu flujo de trabajo ya probado como `workflow_api.json` con `File → Export Workflow (API)`. Consulta [Formato API de flujo de trabajo](/es/development/api-development/workflow-api-format).
  
  
    
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")  # Comfy Cloud es el objetivo predeterminado

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." }); // Comfy Cloud es el objetivo predeterminado

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    

    `"9"` es el ID del nodo de salida. Consulta la [guía del SDK](/es/development/api-development/sdks) para las entradas, el progreso y el manejo de errores.
  

El mismo código del SDK puede apuntar a [despliegues de Comfy API](/es/development/serverless/quickstart) y a [ComfyUI autoalojado](/es/development/deploy/self-hosting). Consulta [Ejecutar flujos de trabajo](/es/development/run-workflows/overview).
