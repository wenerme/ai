ComfyUI es un motor de inferencia GenAI modular que puedes ejecutar como servidor, usar mediante API, ampliar con Nodos personalizados y gestionar desde la línea de comandos. La mayoría del trabajo con la API sigue dos pasos: poner ComfyUI en marcha en algún lugar y luego ejecutar flujos de trabajo contra él desde tu aplicación.

## Casos de uso

  
    Crea la credencial que usan las API de la nube, los Nodos asociados y MCP.
  
  
    Genera con modelos alojados mediante Comfy Router.
  
  
    Llama a un despliegue desde el SDK de Python o de TypeScript.
  
  
    Ejecuta tus propios flujos de trabajo en infraestructura gestionada o en ComfyUI autoalojado.
  
  
    Conecta agentes a ComfyUI mediante MCP y las herramientas de agente.
  
  
    Explora los modelos disponibles en Comfy.org.
