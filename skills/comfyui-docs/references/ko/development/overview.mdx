ComfyUI는 서버로 실행할 수 있고 API로 접근할 수 있으며, 커스텀 노드로 확장하고 명령줄에서 관리할 수 있는 모듈식 GenAI 추론 엔진입니다. 대부분의 API 작업은 두 단계로 진행됩니다. 먼저 ComfyUI를 어딘가에서 실행한 다음, 애플리케이션에서 이에 대한 워크플로를 실행합니다.

## 사용 사례

  
    Cloud API, 파트너 노드, MCP에서 사용하는 자격 증명을 만듭니다.
  
  
    Comfy Router를 통해 호스팅된 모델로 생성하세요.
  
  
    Python 또는 TypeScript SDK로 배포를 호출합니다.
  
  
    관리형 인프라 또는 자체 호스팅 ComfyUI에서 자신의 워크플로를 실행하세요.
  
  
    MCP와 에이전트 도구로 에이전트를 ComfyUI에 연결합니다.
  
  
    Comfy.org에서 사용 가능한 모델을 찾아보세요.
