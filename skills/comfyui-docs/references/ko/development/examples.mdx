## Comfy Router

Comfy Router를 사용하면 하나의 Comfy API 키로 호스팅된 파트너 모델을 호출할 수 있습니다.

  
    Python, TypeScript 또는 cURL로 FLUX를 사용해 첫 이미지를 만들어 보세요.
  
  
    모델을 찾고, 입력을 확인하고, 모델 ID를 복사하세요.
  
  
    Router 모델의 요청 및 응답 형태를 확인하세요.
  
  
    공유 Router 엔드포인트와 헤더를 확인하세요.
  

## Comfy API

자체 ComfyUI 워크플로를 패키징하고, 관리형 GPU 인프라에 배포한 뒤, Comfy API를 통해 실행해 보세요.

  
    Build를 생성하고 릴리스한 다음, 관리형 배포를 시작하세요.
  
  
    배포하기 전에 사용 가능한 리전과 GPU 클래스를 확인하세요.
  
  
    API 형식의 워크플로를 제출하고 그 출력을 다운로드하세요.
  
  
    Python 또는 TypeScript SDK를 배포 환경에 연결하세요.
