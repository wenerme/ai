이 섹션에서는 ComfyUI 프론트엔드 설정 메뉴의 상세한 설정 설명을 다룹니다. 모든 사용자 설정은 자동으로 `ComfyUI/user/default/comfy.settings.json` 파일에 저장됩니다.

`Ctrl + ,` 키보드 단축키를 사용해 설정 패널을 열고, 해당 설정 옵션을 클릭하여 구성할 수 있습니다.

커스텀 노드 역시 메뉴에 해당 설정 카테고리를 등록할 수 있으므로, 현재 공식 문서에는 기본 제공 설정 내용만 포함되어 있습니다. 또한 일부 설정 옵션은 **ComfyUI 데스크톱에서만 유효**하며, 이는 해당 페이지에 명시하였습니다.

## ComfyUI 설정 메뉴

    ComfyUI 계정과 관련된 사용자 설정으로, 주로 파트너 노드를 사용하기 위해 ComfyUI 계정에 로그인하는 데 사용됩니다.
  
  
    크레딧 구매 및 크레딧 잔액 내역 항목으로, ComfyUI 계정에 로그인한 후에만 볼 수 있습니다.

    테마, 배경색, 사이드바 위치 등 ComfyUI의 모양 옵션을 수정합니다.
  
  
    ComfyUI 프론트엔드 확장 플러그인의 활성화/비활성화 상태를 관리합니다.

    데스크톱 업데이트 설정, 미러 설정 등 (ComfyUI 데스크톱에서만 유효)

    ComfyUI 구성 파일을 수정합니다. 이 설정은 ComfyUI 데스크톱에서만 유효합니다.
