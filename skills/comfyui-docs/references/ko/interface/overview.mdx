시각적 UI는 대부분 사용자가 [ComfyUI Server](/ko/development/comfyui-server/comms_overview)를 다루는 방식입니다. 이 페이지는 UI 지도이며, 각 영역과 구성 요소 안내는 아래 링크를 보세요.

[ComfyUI Basic Interface]

[ComfyUI 프론트엔드](https://github.com/Comfy-Org/ComfyUI_frontend)는 별도 프로젝트로 유지됩니다.

## 지역화

영어, 중국어, 러시아어, 프랑스어, 일본어, 한국어를 지원합니다. **설정**을 연 뒤 `Comfy` → `Locale`에서 언어를 고릅니다.

[ComfyUI Localization Support]

## 워크스페이스 지도

[번호 1–6가 표시된 ComfyUI 워크스페이스]

스크린샷의 번호는 아래 표의 영역과 일치합니다:

| # | 영역 | 설명 |
| --- | --- | --- |
| **1** | **왼쪽 사이드바** | Assets, Node Library, Model Library, Workflows, Apps, (켜진 경우) Job History |
| **2** | **캔버스** | 노드를 놓고 연결하는 그래프와 캔버스 컨트롤 |
| **3** | **오른쪽 패널** | 선택 항목의 파라미터, 노드 정보, 설정, 오류 (상단 바 속성 패널 토글로 열림) |
| **4** | **상단 바** | 열린 워크플로, Run / 큐, 로그인, 속성 패널 토글 |
| **5** | **왼쪽 아래** | Help Center, 하단 패널, 설정 |
| **6** | **오른쪽 아래** | 캔버스 컨트롤: 팬, 미니맵, 링크, 줌, 맞춤 |
