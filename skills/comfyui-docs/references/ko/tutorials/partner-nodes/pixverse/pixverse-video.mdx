PixVerse Video는 V5.6, V6, C1, R1 등의 모델을 기반으로 **텍스트 기반 비디오 생성**, **이미지 기반 비디오 생성**, **템플릿 이미지 기반 비디오 생성** 모드를 통해 ComfyUI에서 바로 영화 같은 비디오를 생성할 수 있습니다.

## 주요 기능

- **텍스트 기반 비디오 생성**: 텍스트 프롬프트로 원본 비디오를 생성합니다. 콘셉트 시각화, 스토리보드 작성, 빠른 창작 탐색에 이상적입니다.
- **이미지 기반 비디오 생성**: 참조 이미지를 애니메이트하면서 피사체의 정체성과 장면 구성을 유지해, 정적인 이미지를 자연스러운 움직임으로 살아나게 합니다.
- **템플릿 이미지 기반 비디오 생성**: 입력 이미지에 미리 정의된 모션 템플릿을 적용해 예측 가능하고 반복 가능한 애니메이션 스타일을 제공하며, 제작 파이프라인에 적합합니다.

## 사용 가능한 워크플로

### 텍스트 기반 비디오 생성

텍스트 프롬프트로 원본 비디오를 생성합니다. 장면, 캐릭터, 동작을 설명하면 PixVerse가 그에 맞는 영화 같은 품질의 비디오 클립을 생성합니다.

  
    Comfy Cloud에서 텍스트 기반 비디오 생성 워크플로를 즉시 실행해 보세요.
  
  
    로컬에서 사용할 워크플로 JSON 파일을 다운로드하세요.
  

### 이미지 기반 비디오 생성

참조 이미지를 사용해 원본 피사체, 스타일, 구성을 유지하면서 이미지를 애니메이트하는 비디오를 생성합니다.

  
    Comfy Cloud에서 이미지 기반 비디오 생성 워크플로를 즉시 실행해 보세요.

입력 이미지에 미리 정의된 모션 템플릿을 적용해 예측 가능하고 반복 가능한 애니메이션 결과를 얻습니다. 이 모드는 변동성을 줄여 주므로 일관된 배치 처리에 이상적입니다.
