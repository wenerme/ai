하나의 텍스트 입력에서 서로 다른 목소리로 여러 캐릭터의 대화를 생성합니다. 캐릭터 목소리를 정의하고 대화를 스크립트하면, ElevenLabs가 한 번의 실행으로 각 캐릭터를 지정된 목소리로 렌더링합니다.

## 주요 기능

- **다중 음성 생성**: 한 번의 실행으로 서로 다른 목소리를 가진 여러 캐릭터를 처리합니다
- **스크립트 기반**: 캐릭터 지정이 포함된 구조화된 대화 텍스트를 입력합니다
- **일관된 캐릭터 목소리**: 각 캐릭터가 지정된 목소리 정체성을 유지합니다

## 사용 가능한 워크플로

  
    텍스트에서 다중 음성 대화를 생성합니다.
  
  
    워크플로 JSON을 다운로드합니다.
