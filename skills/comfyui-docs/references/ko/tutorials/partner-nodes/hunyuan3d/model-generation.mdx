Hunyuan 3D 3.0은 텐센트가 개발한 최첨단 3D 생성 모델로, 몇 분 내에 3D 콘텐츠를 제작할 수 있게 해줍니다. 기존의 3D 모델링 파이프라인보다 훨씬 낮은 진입 장벽으로 텍스트 프롬프트, 이미지 또는 스케치로부터 생산 가능한 3D 자산을 생성할 수 있습니다.

ComfyUI는 현재 해당 Hunyuan 3D API를 기본적으로 통합하여, ComfyUI에서 관련 노드를 편리하게 사용해 모델을 생성할 수 있도록 지원합니다.

현재 ComfyUI의 파트너 노드는 다음과 같은 Hunyuan 3D 모델 생성 기능을 지원합니다:
- 텍스트 기반 3D 생성
- 이미지 기반 3D 생성
- 멀티뷰 기반 3D 모델 생성

## 활용 사례

- **게임 개발 아이디어**: 리깅과 실시간 렌더링에 최적화된 토폴로지로 캐릭터, 소품 및 환경을 빠르게 생성
- **제품 및 전자상거래**: 제품 사진을 온라인 표시용 인터랙티브 3D 모델로 변환
- **산업 디자인**: 스케치를 3D 프로토타입으로, 3D 프린팅 준비가 가능한 부품 분해
- **VFX 및 애니메이션**: 전문적인 UV와 PBR 재질을 갖춘 고해상도 자산

## 시작하기

### 1. 워크플로 템플릿 접근

1. 사이드바에서 템플릿 라이브러리를 열어주세요.
2. **3D** → **Hunyuan 3D**로 이동하세요.
3. Hunyuan 3D용 워크플로 템플릿을 선택하세요.

### 2. 워크플로 실행

1. 워크플로 유형에 따라 텍스트 프롬프트, 이미지 또는 스케치를 입력하세요.
2. `실행` 버튼을 클릭하거나 단축키 `Ctrl(cmd) + Enter`를 사용해 모델 생성을 실행하세요.
3. 워크플로가 완료된 후 3D 모델을 미리보기하고 내보내세요.

### HunYuan3D: 텍스트로 모델 생성 {#api_hunyuan3d_text_to_model}

텍스트 프롬프트를 입력하거나 참조 이미지를 업로드하여 상세한 3D 모델 에셋을 생성하세요.

**예시 프롬프트**: "Mechanical dolphin with gears, steampunk"

[HunYuan3D: 텍스트로 모델 생성 워크플로 미리보기]

  
    Comfy Cloud에서 열기
  
  
    JSON 다운로드 또는 템플릿 라이브러리에서 &quot;HunYuan3D: Text to Model&quot; 검색
  

### HY 3D: 이미지로 모델 생성 {#api_hunyuan3d_image_to_model}

이미지를 업로드하여 지오메트리와 PBR 텍스처를 갖춘 3D 모델을 생성하세요. 다양한 각도에서 촬영한 2~4장의 멀티뷰 이미지를 업로드하면 지오메트리와 재질의 정확도가 향상됩니다.

[HY 3D: 이미지로 모델 생성 워크플로 미리보기]

  
    Comfy Cloud에서 열기
  
  
    JSON 다운로드 또는 템플릿 라이브러리에서 &quot;HY 3D: Image to Model&quot; 검색
