Vidu Q1은 모든 핵심 비디오 생성 유형을 처리하는 1세대 Vidu 모델입니다. 텍스트, 이미지, 참조 이미지, 시작 및 종료 프레임, 비디오 확장 등 다양한 입력 모드를 제공하므로 속도와 표현력이 균형을 이루는 범용 제작에 안정적인 선택입니다.

## 주요 기능

- **다섯 가지 생성 모드**: 텍스트 기반 비디오 생성, 이미지 기반 비디오 생성, 레퍼런스 기반 비디오 생성(최대 7개 이미지), 시작-끝 프레임 기반 비디오 생성, 비디오 확장
- **유연한 피사체 레퍼런스**: 다중 레퍼런스 입력에서도 캐릭터와 장면의 정체성을 유지
- **비디오 확장**: 기존 비디오 클립을 자연스럽게 이어서 확장
- **균형 잡힌 성능**: 다양한 제작 시나리오에 적합한 안정적인 품질
