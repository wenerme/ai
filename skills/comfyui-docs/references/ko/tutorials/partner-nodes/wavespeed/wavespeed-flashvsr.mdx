WaveSpeed FlashVSR (FLSH-VSR)은 시간적 일관성을 갖춘 AI 비디오 초해상도 모델로, 프레임 전반에 걸쳐 일관된 디테일을 유지하면서 저해상도 비디오를 업스케일합니다. 아카이빙, AI 비디오 향상, SD-to-HD 변환에 이상적입니다.

## 주요 기능

- **시간적 일관성 업스케일링**: 부드럽고 사실적인 출력을 위해 프레임 간 일관성을 유지합니다.
- **SD-to-HD 변환**: 표준 화질 비디오를 사실적인 디테일이 담긴 고화질로 업스케일합니다.
- **AI 비디오 향상**: 오래된 영상 아카이빙과 압축된 비디오 품질 개선에 이상적입니다.
- **로컬 GPU 불필요**: 모든 처리는 ComfyCloud의 인프라에서 실행됩니다.

## 사용 가능한 워크플로

  ComfyCloud에서 FLSH-VSR 비디오 업스케일 워크플로 실행하기
  로컬 ComfyUI용 워크플로 JSON 다운로드하기
