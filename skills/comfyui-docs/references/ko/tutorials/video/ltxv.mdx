[LTX-Video](https://huggingface.co/Lightricks/LTX-Video)는 lightricks가 개발한 매우 효율적인 비디오 모델입니다. 이 모델의 중요한 점은 길고 상세한 프롬프트를 제공하는 것입니다.

## 다중 프레임 컨트롤

일련의 이미지를 통해 비디오를 제어할 수 있습니다. 입력 이미지를 다운로드할 수 있습니다: [시작 프레임](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/ltxv/multi-frame/house1.png) 및 [종료 프레임](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/ltxv/multi-frame/house2.png).

[LTX-Video 다중 프레임 컨트롤]

비디오를 직접 ComfyUI로 드래그하여 워크플로우를 실행하세요.

## 이미지 기반 비디오 생성

### LTXV 이미지 투 비디오 {#ltxv_image_to_video}

정지 이미지에서 비디오를 생성합니다.

[LTXV 이미지 투 비디오 워크플로 미리보기]

  
    Comfy Cloud에서 열기
  
  
    JSON 다운로드 또는 템플릿 라이브러리에서 &quot;LTXV Image to Video&quot; 검색
  

**입력 자료**

이 파일을 해당 `LoadImage` 노드에 업로드하세요:

  
    `LoadImage` 노드 78 · `ltxv_image_to_video_input_image.jpg`

비디오를 ComfyUI로 직접 드래그하여 워크플로를 실행하세요.

## 텍스트 기반 비디오 생성

### LTXV 텍스트 투 비디오 {#ltxv_text_to_video}

텍스트 프롬프트에서 비디오를 생성합니다.

[LTXV 텍스트 투 비디오 워크플로 미리보기]

  
    Comfy Cloud에서 열기
  
  
    JSON 다운로드 또는 템플릿 라이브러리에서 &quot;LTXV Text to Video&quot; 검색
  

비디오를 직접 ComfyUI로 드래그하여 워크플로를 실행하세요.

## 요구사항

다음 모델을 다운로드하여 아래 지정된 위치에 배치하세요:

  다운로드하여 ComfyUI/models/checkpoints/에 배치

  다운로드하여 ComfyUI/models/text_encoders/에 배치

```
├── checkpoints/
│   └── ltx-video-2b-v0.9.5.safetensors
└── text_encoders/
    └── t5xxl_fp16.safetensors
```
