title: "Deploying ComfyUI"
description: "Compare Comfy Cloud, managed Comfy API deployments, and self-hosting to choose how to run ComfyUI."
---

Choose Comfy Cloud for an always-available managed ComfyUI, Comfy API for a versioned environment deployed as an endpoint, or self-hosting for infrastructure you manage.

  
    Run workflows without creating a Build or deployment.
  
  
    Package models and custom nodes into a managed, autoscaling endpoint.
  
  
    Run ComfyUI on your own hardware, rented GPUs, or containers.
  

All three options run [API-format workflows](/development/api-development/workflow-api-format). Choose based on whether you want Comfy to manage the environment or want to manage it yourself.

## Next step: run workflows against it

Once a deployment is live, see [Running Workflows](/development/run-workflows/overview) to call it from your application. The [Comfy SDKs](/development/api-development/sdks) work against every deployment target; self-hosted instances additionally need the [API Proxy](/development/comfyui-server/api-proxy) during the v2 beta.
