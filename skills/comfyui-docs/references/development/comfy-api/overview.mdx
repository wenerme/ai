The public API for running ComfyUI headlessly has evolved over time. For new integrations, use [Comfy API v2](/api-reference/v2/overview). It is supported on open-source ComfyUI (during the beta, via the [API Proxy](/development/comfyui-server/api-proxy)), Comfy Cloud, and [serverless deployments on the Developer Platform](/development/serverless/overview). Older versions include the [v1 Cloud API](/development/cloud/overview), which is deprecated.

  
    The versioned HTTP API for running workflows from any language, on any surface. Start here.
  
  
    The older Comfy Cloud API, still available for existing integrations.
