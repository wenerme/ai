PixVerse Video は、**テキストから動画へ**、**画像から動画へ**、**テンプレート画像から動画へ**の各モードを通じて、ComfyUI 内で直接、映画的なビデオ制作を可能にします。V5.6、V6、C1、R1 などのモデルによって動作します。

## 主な機能

- **テキストから動画へ**：テキストプロンプトからオリジナルのビデオを生成します。コンセプトの可視化、ストーリーボード作成、素早いクリエイティブな試行錯誤に最適です。
- **画像から動画へ**：参照画像をアニメートしながら、被写体の同一性とシーンの構図を維持します。静止画を自然な動きで生き生きとさせます。
- **テンプレート画像から動画へ**：入力画像に事前定義されたモーションテンプレートを適用し、制作パイプラインに適した予測可能で再現性のあるアニメーションスタイルを実現します。

## 利用可能なワークフロー

### テキストから動画へ

テキストプロンプトからオリジナルのビデオを作成します。シーン、キャラクター、アクションを記述すると、PixVerse が映画品質のビデオクリップを生成します。

  
    Comfy Cloud でテキストから動画へのワークフローをすぐに実行できます。
  
  
    ローカルで使用するためのワークフロー JSON ファイルをダウンロードします。
  

### 画像から動画へ

参照画像を用意し、元の被写体、スタイル、構図を維持したまま、その画像をアニメートするビデオを生成します。

  
    Comfy Cloud で画像から動画へのワークフローをすぐに実行できます。
  
  
    ローカルで使用するためのワークフロー JSON ファイルをダウンロードします。
  

### テンプレート画像から動画へ

入力画像に事前定義されたモーションテンプレートを適用し、予測可能で再現性のあるアニメーション結果を得ます。このモードはばらつきを抑えるため、一貫したバッチ処理に最適です。

  
    Comfy Cloud でテンプレート画像から動画へのワークフローをすぐに実行できます。
  
  
    ローカルで使用するためのワークフロー JSON ファイルをダウンロードします。
