RMBG 3.0 は Bria の3番目の背景除去モデルであり、セグメンテーションネットワークではなく生成モデルをベースに構築された最初のモデルです。硬いバイナリマスクではなく、柔らかなグレースケールのアルファマットをレンダリングするため、髪、毛皮、メッシュ、ベール、モーションブラーは部分的な透明性を保ちます。

ベースは Fibo 2.0 で、8B の diffusion transformer と Qwen3-VL-4B のプロンプト・画像エンコーダを備え、classifier-free guidance なしで4サンプリングステップに蒸留されています。ComfyUI のサポートは [ComfyUI #17240](https://github.com/Comfy-Org/ComfyUI/pull/17240) で追加され、テンプレートには ComfyUI 0.46.0 以降が必要です。

ワークフローは画像を1枚入力し、RGBA カットアウト、背景プレート、処理済みマットの3つを出力します。

## 背景を除去: RMBG 3.0 {#utility_rmbg3_remove_background}

[前後の比較を含む RMBG 3.0 の背景除去ワークフロー]

  
    JSON をダウンロードするか、テンプレートライブラリで &quot;背景を除去: RMBG 3.0&quot; を検索してください
  

**モデル**

  
    rmbg3_int8_convrot.safetensors &#8594; ComfyUI/models/diffusion_models/
  
  
    qwen3vl_4b_int8_convrot.safetensors &#8594; ComfyUI/models/text_encoders/
  
  
    flux2-vae.safetensors &#8594; ComfyUI/models/vae/
  

同じリポジトリには diffusion model と text encoder の BF16 版も用意されています。メモリと引き換えに精度を優先したい場合はこちらを使用してください。

**入力マテリアル**

  
    `LoadImage` ノードに読み込む
  

1. 写真を `LoadImage` ノードにドロップします。
2. `auto_prompt` をオンにします。テンプレートの初期値はオフです。オフのままだと固定の指示が送信され、`subject_note` は使われません。
3. 任意: `subject_note` にマテリアルについての短い一文を記述します。例: `Clear glass bottle, paper label, metal cap`
4. ワークフローを実行します。`SaveImage` は両方の結果を `ComfyUI/output/rmbg3/` に出力します。

## ワークフローのコントロール項目

- `auto_prompt`: オンの場合、視覚モデルが画像と `subject_note` からマッティング指示を作成します。オフの場合、モデルが学習時に用いた固定の指示がそのまま送信され、`subject_note` は無視されます。
- `cfg`: 1.0 のままにしてください。このモデルはガイダンスなしで蒸留されているため、値を大きくするとソースへの忠実度を犠牲にして透明度が優先されます。
- `alpha_brightness`、`alpha_contrast`、`mask_threshold`、`hard_mask`: マットの後処理です。柔らかいエッジを保つには `hard_mask` をオフのままにします。
- `mask_expand`、`mask_tapered_corners`: 適用前にマットを拡張し、角を丸めます。

## 切り抜きがうまくいかない場合

| 症状 | 対処 |
| :--- | :--- |
| ガラス、ベール、煙が不透明に戻る | `auto_prompt` をオンにし、`subject_note` でマテリアルを説明してから、`cfg` を 1.5 または 2.0 に上げます |
| 背景全体にグレーの霞がかかる | `alpha_brightness` を下げるか、`hard_mask` をオンにします |
| 色付きガラスが不透明のまま | `alpha_brightness` を下げるか、その領域を手動で塗ります |

モデル自体に由来する制限が 2 つあります。非常に複雑なシーンやコントラストの低いシーンでは、被写体の隣にある草、小道具、ウォーターマークまで取り込んでしまうことがあり、昆虫の羽のような細かい構造ではピクセルが失われることがあります。
