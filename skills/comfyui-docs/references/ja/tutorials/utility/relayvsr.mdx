RelayVSRは実写映像を1パスでアップスケールします。1ステップのWan2.2 5Bモデルが15フレームごとに参照latentを書き込み、小さなFlashデコーダーがそれらのlatentとオリジナルの低品質クリップから間のフレームを埋めます。ComfyUIのサポートは[ComfyUI #17511](https://github.com/Comfy-Org/ComfyUI/pull/17511)で追加されました。

フレームレートとオーディオはそのまま通されるため、再スケールされるのは映像だけです。スケール倍率はウィジェットではなくcheckpointから決まります。2xモデルは2x VAEでのみ動作し、組み合わせを混在させると失敗します。

## モデル

希望するスケールのペアをダウンロードし、各ファイルをカードに表示されているフォルダーに配置します。

  
    relayvsr_x2_lightx2v_int8_convrot.safetensors &#8594; ComfyUI/models/diffusion_models/
  
  
    relayvsr_flash_vae_x2_fp32.safetensors &#8594; ComfyUI/models/vae/
  
  
    relayvsr_x4_int8_convrot.safetensors &#8594; ComfyUI/models/diffusion_models/
  
  
    relayvsr_flash_vae_x4_fp32.safetensors &#8594; ComfyUI/models/vae/
  

2x ペアは、ビデオ生成後のステップ用に [LightX2V](https://huggingface.co/lightx2v/RelayVSR_X2) によって再トレーニングされているため、MiniMax-H3 の 768 x 1344 のクリップは 1536 x 2688 で出力されます。4x ペアはオリジナルの RelayVSR スケールです。

## ビデオアップスケール: RelayVSR 2x {#utility_relayvsr_video_x2_upscale}

以下のワークフローでクリップを2倍にアップスケールします。アップスケーラーはサブグラフ内で動作するため、キャンバスにはビデオの入力と出力だけが表示されます。

[RelayVSR 2x ビデオアップスケールワークフローのプレビュー]

  
    JSON をダウンロードするか、テンプレートライブラリで &quot;RelayVSR 2x&quot; を検索してください
  

**入力素材**

  
    `LoadVideo` · `utility_relayvsr_video_x2_upscale_input.mp4`
  

1. `Load Video` ノードでクリップを読み込みます。テンプレートでは `Trim Video` ノードによって最初の5秒にトリミングされるため、長いクリップの場合はこの再生時間を延ばすか、長い映像を複数回に分けてアップスケールしてください。
2. ワークフローを実行します。結果は `Save Video` によって `ComfyUI/output/video/` に保存されます。

4倍にする場合は、サブグラフ内の2つのローダーの値を入れ替えます。`UNETLoader` を `relayvsr_x4_int8_convrot.safetensors` に、`VAELoader` を `relayvsr_flash_vae_x4_fp32.safetensors` に変更します。それ以外に変更はありません。

メモリ不足で処理が失敗する場合は、クリップをトリミングして複数回に分けてアップスケールしてください。
