**Qwen-Image-Edit-2511** は、Qwen-Image-Edit-2509 の強化版であり、一貫性の大幅な向上を含む複数の改良が施されています。このモデルは、Qwen-Image 固有のテキストレンダリング機能を編集タスクへと拡張し、意味的および外観的な両面から精密なテキスト編集を可能にします。

**Qwen-Image-Edit-2511 の主な強化点**:
- **画像ドリフトの軽減**: 編集操作中の安定性が向上
- **キャラクターの一貫性の向上**: 創意工夫を伴う編集において、人物のアイデンティティおよび視覚的特徴をより適切に保持
- **多人物間の一貫性**: 複数の人物画像を高忠実度で融合し、自然なグループショットを生成
- **LoRA 機能の統合**: 人気のあるコミュニティ製 LoRA をベースモデルに直接組み込み
- **産業デザイン生成機能の強化**: 大量の工業製品設計およびマテリアル置換をより効率的にサポート
- **幾何学的推論能力の強化**: デザインやアノテーション用の補助構成線を直接生成

### Qwen-Image-Edit-2511 マルチアングル：3D カメラノードを使う {#template_qwen_multiangle_app}

写真を 1 枚読み込み、3D ビューで被写体のまわりをカメラで回り込みます。選んだ角度で Qwen-Image-Edit-2511 が同じ被写体を描き直します。このテンプレートは編集モデルとマルチアングル LoRA を組み合わせており、1 枚の入力画像を好きな角度から撮り直せます。

[Qwen-Image-Edit-2511 マルチアングルワークフローのプレビュー]

  
    Comfy Cloud で開く
  
  
    JSON をダウンロード、またはテンプレートライブラリで「Generate Multiple Angles with 3D Camera Node」を検索
  

**入力素材**

ファイルを `LoadImage` ノードに読み込みます：

  
    `LoadImage` ノード 1
  

#### カメラアングルの操作

**Compose Camera Angle Prompt** ノードは角度の入力欄の上に 3D ビューを追加します。ビューで視点を選ぶと、`front view eye-level shot medium shot` のようなショット記述がワークフローのプロンプトに書き込まれるため、手入力は不要です。視点を動かすと角度の入力欄も追従します。

- **Camera / Object**：**Camera** は被写体のまわりを移動し、**Object** はレンズ越しに被写体の向きを変えます。
- **Horizontal angle / Vertical angle / Shot size**：名称で選べます。水平は `Front` から `Front left` までの 8 方向、垂直は `Low angle` から `High angle` までの 4 段階、ショットサイズは `Wide shot` から `Close-up` までの 3 段階です。3D ビュー内のドラッグでも同じ値が入ります。
- **Preview**：カメラのフレームに何が入るかをピクチャーインピクチャーで表示します。

ノードの任意の画像入力に画像を接続すると、被写体の正面に表示され、回り込み中に左右が分かりやすくなります。

Turbo モード（`enable_turbo_mode`、サブグラフノード上のウィジェット）は既定でオンです。4 ステップ、CFG 1、4 ステップ Lightning LoRA を使います。オフにすると 40 ステップ、CFG 4、Lightning LoRA なしで生成します。
