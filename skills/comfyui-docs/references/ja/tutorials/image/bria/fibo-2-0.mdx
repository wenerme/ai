FIBO 2.0 は Bria の 8B 画像モデルで、単一のウェイトセットで生成と編集を行います。オープンウェイト版はクレジットを使わず ComfyUI のローカルで動作し、FLUX.2 VAE の潜在空間で処理し、プロンプトは Qwen3-VL-4B でエンコードします。

テンプレートは 2 つあります。**Fibo 2.0 Turbo: 画像編集** は蒸留版で、方向性の素早い確認に向きます。**Fibo 2.0 Dev: 画像編集** は蒸留していないベースを動かし、最もきれいな編集結果になります。どちらも参照画像と 1 行の指示を入力します。

## Fibo 2.0 Turbo: 画像編集 {#image_fibo2_edit_turbo_pe}

![Fibo 2.0 Turbo: 画像編集、参照画像](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/image_fibo2_edit_turbo_pe-1.webp)

![Fibo 2.0 Turbo: 画像編集、結果](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/image_fibo2_edit_turbo_pe-2.webp)

  
    Turbo の画像編集ワークフローを Comfy Cloud で実行
  
  
    ワークフローをダウンロード、またはテンプレートライブラリで "Fibo 2.0 Turbo: Image Edit" を検索
  

  
    LoadImage ノード用のサンプル参照画像
  

参照画像を読み込み、変更したい領域が完成後にどう見えるかを `prompt` に書き、実行します。

## Fibo 2.0 Dev: 画像編集 {#image_fibo2_edit_dev_pe}

![Fibo 2.0 Dev: 画像編集、参照画像](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/image_fibo2_edit_dev_pe-1.webp)

    Dev の画像編集ワークフローを Comfy Cloud で実行
  
  
    ワークフローをダウンロード、またはテンプレートライブラリで "Fibo 2.0 Dev: Image Edit" を検索
  

  
    LoadImage ノード用のサンプル参照画像
  

同じグラフを蒸留していないウェイトで動かします。サンプリングは約 12 倍かかり、テクスチャの細部まで描き分けます。同梱の構造化 `negative_prompt` はそのまま残してください。

## モデルのダウンロード

どちらのテンプレートも int8_convrot ファイル、bf16 の 4B テキストエンコーダー、そしてプロンプトエンハンサーが参照画像を読むための 8B エンコーダーを読み込みます。bf16 の拡散モデルは同じウェイトのフル精度版で、サイズは約 2 倍です。

  
    fibo2_edit_turbo_int8_convrot.safetensors &#8594; ComfyUI/models/diffusion_models/
  
  
    fibo2_dev_int8_convrot.safetensors &#8594; ComfyUI/models/diffusion_models/
  
  
    fibo2_edit_turbo_bf16.safetensors &#8594; ComfyUI/models/diffusion_models/
  
  
    fibo2_dev_bf16.safetensors &#8594; ComfyUI/models/diffusion_models/
  

  
    qwen3vl_4b_bf16.safetensors &#8594; ComfyUI/models/text_encoders/
  
  
    qwen3vl_4b_int8_convrot.safetensors &#8594; ComfyUI/models/text_encoders/
  
  
    qwen3vl_8b_int8_convrot.safetensors &#8594; ComfyUI/models/text_encoders/
  
  
    flux2-vae.safetensors &#8594; ComfyUI/models/vae/
  

  
    オプションの Turbo LoRA、Dev ベースをより速く動かします &#8594; ComfyUI/models/loras/
