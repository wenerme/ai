[LTX-Video](https://huggingface.co/Lightricks/LTX-Video) は Lightricks 社による非常に効率的な動画モデルです。このモデルを使用する際の重要な点は、詳細な説明を含む長いプロンプトを提供することです。

## マルチフレーム制御

一連の画像を使用して動画を制御できます。入力画像は以下からダウンロードできます：[開始フレーム](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/ltxv/multi-frame/house1.png) および [終了フレーム](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/ltxv/multi-frame/house2.png)。

[LTX-Video マルチフレーム制御]

動画を直接 ComfyUI にドラッグするとワークフローを実行できます。

## テキストから動画

### LTXV テキストから動画 {#ltxv_text_to_video}

テキストプロンプトから動画を生成します。

[LTXV テキストから動画ワークフローのプレビュー]

  
    Comfy Cloud で開く
  
  
    JSON をダウンロードするか、テンプレートライブラリで「LTXV Text to Video」を検索してください
  

動画を直接 ComfyUI にドラッグするとワークフローを実行できます。

## 要件

以下のモデルをダウンロードし、下記に指定された場所に配置してください：

  ダウンロードして ComfyUI/models/checkpoints/ に配置

  ダウンロードして ComfyUI/models/text_encoders/ に配置

```
├── checkpoints/
│   └── ltx-video-2b-v0.9.5.safetensors
└── text_encoders/
    └── t5xxl_fp16.safetensors
```
