[HunyuanVideo 1.5](https://github.com/Tencent/HunyuanVideo) は、テンセントの Hunyuan チームによって開発された、軽量な 8.3B パラメータモデルです。消費者向け GPU（24GB VRAM）でフラッグシップ級の動画生成を実現し、品質を損なうことなく参入障壁を劇的に下げます。

## モデルの特徴

- **コンパクトながら高性能**: 消費者向けハードウェアで動作しながら、より大型のモデルに匹敵する SOTA 性能を提供します。
- **多様な生成**: 卓越した一貫性を保ちながら、高品質なテキストから動画（Text-to-Video）および画像から動画（Image-to-Video）（5-10 秒）をサポートします。
- **精密な制御**: カメラワーク、物理効果、感情表現に対して強力な指示従順性を発揮します。
- **映画級クオリティ**: プロフェッショナルな美的表現を備えたネイティブ 720p 出力（1080p へアップスケール可能）。
- **豊富な機能**: 多様なスタイル（写実的、アニメ、3D）および動画内テキストレンダリング（中国語/英語）をサポートします。

## すべてのワークフローで共通のモデル

以下のモデルはテキストから動画および画像から動画の両ワークフローで使用されます。ダウンロードして指定ディレクトリに保存してください。

  
    qwen_2.5_vl_7b_fp8_scaled.safetensors。<code>ComfyUI/models/text_encoders/</code> に保存
  
  
    byt5_small_glyphxl_fp16.safetensors。<code>ComfyUI/models/text_encoders/</code> に保存
  
  
    hunyuanvideo15_vae_fp16.safetensors。<code>ComfyUI/models/vae/</code> に保存

## Hunyuan Video 1.5 テキストから動画ワークフロー

HunyuanVideo 1.5 テキストから動画は、自然言語の説明から 5-10 秒の動画を生成し、品質を向上させながら VRAM 要件を削減します。

![ComfyUI ワークフロー - Hunyuan Video 1.5 T2V](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/video_hunyuan_video_1.5_720p_t2v-1.webp)

  
    Comfy Cloud で開く
  
  
    JSON をダウンロード、またはテンプレートライブラリで &quot;Hunyuan Video 1.5 T2V&quot; を検索
  

### モデルダウンロード

  
    hunyuanvideo1.5_720p_t2v_fp16.safetensors。<code>ComfyUI/models/diffusion_models/</code> に保存
  

#### モデル保存場所

```
ComfyUI/
├── 📂 models/
│   ├── 📂 text_encoders/
│   │   ├── qwen_2.5_vl_7b_fp8_scaled.safetensors       // 共有モデル
│   │   └── byt5_small_glyphxl_fp16.safetensors           // 共有モデル
│   ├── 📂 vae/
│   │   └── hunyuanvideo15_vae_fp16.safetensors           // 共有モデル
│   └── 📂 diffusion_models/
│       └── hunyuanvideo1.5_720p_t2v_fp16.safetensors     // T2V モデル
```

### ワークフローの実行手順

1. `DualCLIPLoader` ノードに以下のモデルが読み込まれていることを確認：
   - clip_name1: `qwen_2.5_vl_7b_fp8_scaled.safetensors`
   - clip_name2: `byt5_small_glyphxl_fp16.safetensors`
2. `Load Diffusion Model` ノードに `hunyuanvideo1.5_720p_t2v_fp16.safetensors` が読み込まれていることを確認
3. `Load VAE` ノードに `hunyuanvideo15_vae_fp16.safetensors` が読み込まれていることを確認
4. `Queue` ボタンをクリックするか、ショートカット `Ctrl(Cmd) + Enter` でワークフローを実行

ワークフローには超解像アップスケーラーノードが含まれています。有効にすると、`hunyuanvideo1.5_1080p_sr_distilled_fp16.safetensors` を使用して出力を 1080p にアップスケールします。

## 超解像アップスケーラー

両ワークフローには、720p 出力動画を 1080p にアップスケールできる超解像ノードが含まれています。このオプションのアップスケーラーは蒸留モデルを使用し、効率的な高解像度出力を実現します。
