## モデル API

1つの Comfy APIキーで、Comfy Router を使ってホストされたパートナーモデルを呼び出します。

  
    Python、TypeScript、cURL で Flux を使った最初の画像を作成します。
  
  
    モデルを探し、その入力を確認し、モデル ID をコピーします。
  
  
    Router モデルのリクエストとレスポンスの形状を確認します。
  
  
    共有の Router エンドポイントとヘッダーを調べます。
  

## Comfy API

独自の ComfyUI ワークフローをパッケージ化し、マネージド GPU インフラストラクチャにデプロイして、Comfy API 経由で実行します。

  
    Build を作成してリリースし、マネージドデプロイを開始します。
  
  
    デプロイする前に、利用可能なリージョンと GPU クラスを確認します。
  
  
    API フォーマットのワークフローを送信し、その出力をダウンロードします。
  
  
    Python または TypeScript SDK を自分のデプロイ先に向けます。
