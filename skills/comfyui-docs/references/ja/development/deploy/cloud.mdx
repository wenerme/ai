Comfy Cloud は、フルマネージドで常時利用可能な ComfyUI 環境です。ブラウザでワークフローを構築することも、SDK から実行することもできます。作成が必要な Build やデプロイメントはありません。

  Comfy Cloud を初めて使う場合は、[Comfy Cloud の紹介](/ja/get_started/cloud) から始めてください。このクイックスタートでは、アプリからワークフローを実行する方法を説明します。

## クイックスタート

有料のサブスクリプション、[APIキー](/ja/development/api-development/getting-an-api-key)、API 形式のワークフローが必要です。[Comfy SDK](/ja/development/api-development/sdks) はデフォルトで Cloud をターゲットにします。

  
    [platform.comfy.org](https://platform.comfy.org) で APIキーを作成します。詳細は [APIキーの取得](/ja/development/api-development/getting-an-api-key) を参照してください。
  
  
    
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    
  
  
    クラウドエディタで、テスト済みのワークフローを `File → Export Workflow (API)` で `workflow_api.json` として保存します。詳細は [ワークフローAPI形式](/ja/development/api-development/workflow-api-format) を参照してください。
  
  
    
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")  # Comfy Cloud がデフォルトのターゲットです

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." }); // Comfy Cloud がデフォルトのターゲットです

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    

    `"9"` は出力ノードのIDです。入力、進捗、エラー処理については [SDKガイド](/ja/development/api-development/sdks) を参照してください。
  

同じ SDK のコードで、[Comfy API デプロイメント](/ja/development/serverless/quickstart) と [セルフホストの ComfyUI](/ja/development/deploy/self-hosting) をターゲットにすることもできます。詳しくは [ワークフローの実行](/ja/development/run-workflows/overview) を参照してください。
