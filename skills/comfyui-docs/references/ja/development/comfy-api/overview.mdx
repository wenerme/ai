ComfyUIをヘッドレスで実行するためのパブリックAPIは、時間とともに進化してきました。新しい連携には、[Comfy API v2](/ja/api-reference/v2/overview)を使用してください。これは、オープンソースのComfyUI（ベータ期間中は[API Proxy](/ja/development/comfyui-server/api-proxy)経由）、Comfy Cloud、および[Developer Platform上のComfy APIデプロイメント](/ja/development/serverless/overview)でサポートされています。旧バージョンには、非推奨となった[v1 Cloud API](/ja/development/cloud/overview)があります。

  
    あらゆる言語、あらゆる環境でワークフローを実行するためのバージョン管理されたHTTP API。まずはここから始めてください。
  
  
    旧バージョンのComfy Cloud APIで、既存の連携向けに引き続き利用可能です。
