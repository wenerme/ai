Desktop のスナップショットまたはワークフローをすでにお持ちですか？ 以下から該当する手順を使って Build を開始し、リリースする前にその内容を確認してください。

## Comfy Desktop スナップショット

スナップショットを使用すると、Desktop インスタンスの ComfyUIバージョン、カスタムノード、Python パッケージを Build に引き継ぐことができます。

1. Comfy Desktop で、インスタンスの**管理**パネルを開き、**スナップショット**を選択します。ビルドする環境のスナップショットを選び、その**エクスポート**ボタンをクリックします。現在の状態が一覧にない場合は、先に手動でスナップショットを作成してください。詳しくは [Desktop スナップショットの手順](/ja/installation/desktop/usage/snapshots#スナップショットタブの概要) を参照してください。
2. [Comfy API Build Wizard](https://platform.comfy.org/?onboarding=comfyapi) を開き、スナップショットファイルをインポートします。
3. Build の内容を確認し、リリースを作成する前に不足しているモデルや依存関係を追加または修正します。

[Comfy Desktop の Snapshots タブ（選択済みスナップショットのエクスポートボタンが強調表示）]

## ワークフロー JSON

保存済みのワークフローファイルを使用して、Build Wizard で Build を構成します。

1. [Comfy API Build Wizard](https://platform.comfy.org/?onboarding=comfyapi) を開きます。
2. ワークフロー JSON をインポート手順にドラッグします。
3. Build の内容を確認し、リリースを作成する前に不足しているモデルや依存関係を追加または修正します。

[ワークフロー JSON をインポートした Comfy API Build Wizard とビルド設定の手順]

ウィザードはワークフローを検査し、続行する前に Build 設定を提案します。
