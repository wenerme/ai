クレジットは **Partner Nodes**（クローズドソースモデルへの API 呼び出し）を動かすために使います。ローカルのグラフ実行とオープンソースノードは引き続き完全に無料です。クレジットが必要なのは Partner Nodes や Cloud の課金機能を使うときだけです。

**設定 → ユーザー** でサインインしたあと、**設定 → ワークスペース → プランとクレジット** を開きます。Comfy Cloud では、プロフィールメニューの **Manage plan / プラン管理** からも同じパネルを開けます。

[プランとクレジット（Cloud）]

ComfyUI はローカルユーザー向けに常に完全オープンソースかつ無料です。スクリーンショットの残高は説明用の例示データです。

## プランとクレジットの内容

**設定 → ワークスペース → プランとクレジット** を開きます。ローカルインストールでは、サインイン後にサイドバーの Workspace 配下にプランとクレジットが表示されます（Members / Invoices はありません）：

[プランとクレジット（ローカル）]

| タブ | 内容 |
| --- | --- |
| **Credits（クレジット）** | 残高、チャージ、プラン概要（ローカルはクレジットパネルを埋め込み、Cloud はワークスペースのサブスクリプション表示） |
| **Activity（アクティビティ）** | クレジット消費の利用履歴 |
| **Invoices（請求書）** | Cloud のみ。ワークスペースのサブスクリプション管理権限があるユーザー向け — 次回請求と Stripe 履歴 |

[Activity タブ]

[Invoices タブ（Cloud）]

Cloud のプラン変更、請求ポータル、支払い失敗についてはサポートガイドを参照してください：

  
    プラン変更、Billing & invoices、Team と Personal
  
  
    Stripe 請求ポータルの請求書と PDF
  

## クレジットの購入方法

**設定 → ユーザー** を開いてログインします。
[ログインインターフェース]

ログイン後、**設定 → ワークスペース → プランとクレジット**（または Cloud プロフィール → **プランを管理**）を開きます。
[プランとクレジット]

[購入量を設定]
ポップアップで購入するクレジット量を設定し、**購入** をクリックします。

[購入を確認]
金額を確認したあと、Stripe チェックアウトに進んで支払いを完了します。ComfyUI アカウントと同じメールアドレスを使用してください。

[購入後のプランとクレジット]
**プランとクレジット** に戻り、残高が更新されていることを確認します。必要に応じて更新または再起動してください。

  現時点では、未使用クレジットの返金はサポートしていません。

  複数のデバイスで同じアカウントにログインすることはできます。他のユーザーアカウントとのクレジット共有はサポートしていません。Cloud Team ワークスペースでは、メンバーがオーナー設定の上限内でワークスペース残高を共有します。
  

  
  実行前に API / Partner Node の価格バッジを確認してください。実際のコストは画像サイズ、生成数、その他のパラメータで変わることがあります。
