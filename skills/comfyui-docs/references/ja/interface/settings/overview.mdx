このセクションでは、ComfyUI フロントエンドの設定メニューにある設定項目について詳しく説明します。すべてのユーザー設定は自動的に `ComfyUI/user/default/comfy.settings.json` ファイルに保存されます。

`Ctrl + ,` キーボードショートカットを使用して設定パネルを開き、対応する設定オプションをクリックして設定できます。

カスタムノードもメニューに対応する設定カテゴリを登録できるため、公式ドキュメントでは現時点でネイティブ設定のコンテンツのみを掲載しています。また、一部の設定オプションは **Comfyデスクトップでのみ有効** であり、該当ページで注記しています。
