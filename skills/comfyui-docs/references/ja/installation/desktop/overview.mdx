**Comfy Desktop** は、一つのランチャーから複数の ComfyUI インスタンスをインストール、管理、起動できるデスクトップアプリケーションです。

簡単に言うと：**Comfy Desktop** が **ComfyUI**（ノードベースの生成 AI エンジン）を管理・起動するアプリです。ComfyUI を別途インストールする必要はありません。Comfy Desktop がインストール、Python 環境、依存関係を自動的に処理します。各 ComfyUI インスタンスは独自のバージョン、カスタムノード、設定を持ち、独立して動作します。

[Comfy Desktop スクリーンショット]

Comfy Desktop は **Windows 10+**、**macOS 13+（Apple Silicon）**、**Linux**（公式の `.deb` および AppImage パッケージ）に対応しています。各スタンドアロンインストールには少なくとも **4.85 GB** のディスク容量と **8 GB RAM（推奨 16 GB）** が必要です。詳細は各プラットフォームのインストールページをご覧ください。

## はじめる

プラットフォームを選択して開始してください：

  
    Windows 10 以降向けのステップバイステップのインストールガイド。
  

  
    macOS 13+（Apple Silicon）向けのステップバイステップのインストールガイド。
  

  
    公式の `.deb` または AppImage をインストールするか、ソースからビルドします。

## Legacy Desktop からの移行

旧バージョンの Legacy Desktop（シングルインストールのデスクトップアプリ）を引き続き使用している場合でも、カスタムノード、ワークフロー、モデルを新しい Comfy Desktop に移行できます。既存のデータは保持され、手動での移行は不要です。

  
    Legacy Desktop から Comfy Desktop へのステップバイステップの移行ガイド。
