Kling Lip Sync Text to Video ノードは、動画ファイル内の口の動きをテキストプロンプトに合わせて同期します。入力動画を受け取り、キャラクターの口の動きが指定されたテキストに合わせて調整された新しい動画を生成します。このノードは音声合成を使用して、自然な発話同期を作成します。
