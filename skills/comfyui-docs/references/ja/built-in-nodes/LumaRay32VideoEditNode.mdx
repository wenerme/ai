このノードは、Luma Ray 3.2 を使用して既存の動画を新しいプロンプトで再レンダリングし、元の動きを保持しながらスタイルの変更、照明の調整、要素の追加または削除を可能にします。ソース動画は最大18秒まで対応し、編集後の動画はソースの元の長さを維持します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `ビデオ` | 編集するソース動画。最大18秒。 | VIDEO | はい | - |
| `プロンプト` | 希望する編集内容を記述します。 | STRING | はい | - |
| `解像度` | 編集後の動画の出力解像度。 | COMBO | はい | `"360p"``"540p"``"720p"``"1080p"` |
| `強度` | ソースを保持するか再解釈するかの強度。"auto" は Ray 3.2 が自動選択します。adhere_* は最も保持し、flex_* はバランスが取れており、reimagine_* は最も変化します。（デフォルト: "auto"） | COMBO | はい | `"auto"``"adhere_1"``"adhere_2"``"adhere_3"``"flex_1"``"flex_2"``"flex_3"``"reimagine_1"``"reimagine_2"``"reimagine_3"` |
| `シード` | 再現性のためのシード値。 | INT | はい | - |

| `解像度` | 編集後の動画の出力解像度。（デフォルト："720p"） | COMBO | はい | `"360p"``"540p"``"720p"``"1080p"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `generation_id` | 編集後の動画出力。 | VIDEO |
| `generation_id` | 生成リクエストの一意識別子。 | STRING |
