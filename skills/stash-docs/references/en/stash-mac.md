# Stash Mac

Stash Mac includes all the features of the iOS version. Additionally, designed specifically for the macOS platform, Stash Mac will support even more features than the iOS version.

## Native Application

Stash Mac is designed specifically for the macOS platform, natively supporting both Intel and Apple Silicon Mac architectures. Furthermore, it supports a series of macOS native interactions such as booting at startup, menu bar shortcuts, keyboard shortcuts, and more.

## Process-Based Rules

Due to macOS's open design, Stash Mac can specify independent routing rules for processes. In the Stash Dashboard, you can view process information corresponding to each local TCP/UDP connection, and even utilize Stash to build your personal network firewall.

## Gateway Mode

Have multiple devices in your local network? Stash Mac supports gateway mode, simply point the gateway of devices in the local network to the macOS running Stash in enhanced mode to provide a seamless transparent proxy experience. Stash Mac is well-prepared to act as a routing gateway, [click here to learn more](/features/provide-proxy-to-lan-device).
