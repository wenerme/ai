# Welcome to Stash App 👋

Stash is the best implementation client for the Clash Premium kernel on Apple devices, fully adapting Clash features for iOS, tvOS, macOS, and visionOS platforms.

![](/stash-apple.png)

Moreover, based on Apple's platform features, Stash provides the following additional features on top of Clash Premium functionality:

- **Configuration Sync**: Stash's configuration files, rules, subscriptions, and more can be synchronized across all devices via iCloud, enabling one configuration to be shared across multiple devices.
- **Remote Control**: The address of Stash devices is securely stored in iCloud, allowing devices logged in with the same iCloud account to directly control Stash devices within the local network remotely, without the need to manually manage addresses and passwords.
- **Quick Actions**: Users can quickly start, stop, switch nodes, and perform other operations on Stash through widgets, the Today view, Widget, Siri shortcuts, and more.
- **On-Demand Connection**: Based on Apple's VPN On Demand feature, users can automatically connect or disconnect Stash according to conditions such as SSID, domain name, or application.
- **Enhanced Network Engine**: Stash supports MitM functionality, allowing users to inspect HTTPS traffic and provides JavaScript script rewriting of content based on the Apple WebKit engine.
- **Deep Customization**: To better adapt to mobile devices, Stash deeply customizes its kernel and runtime code, excellently managing memory, power, and network resource consumption.
- **Rich Proxy Protocols**: Keeping up with the open-source community developments, Stash supports various popular proxy protocols such as Hysteria, VLESS, TUIC, and WireGuard.
