# Getting started

Last updated Aug 21, 2026|Copy as Markdown|[View as Markdown](https://developers.cloudflare.com/pages/get-started/index.md)|[Agent setup](https://developers.cloudflare.com/agent-setup/)

Are you sure you want to use Pages?

[Workers supports most Pages use cases and offers a broader feature set](https://developers.cloudflare.com/workers/static-assets/migration-guides/migrate-from-pages/). It is Cloudflare's primary platform for building applications. Start new projects with Workers.

Choose a setup method for your Pages project:

* [C3 CLI](https://developers.cloudflare.com/pages/get-started/c3/)
* [Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)
* [Git integration](https://developers.cloudflare.com/pages/get-started/git-integration/)
