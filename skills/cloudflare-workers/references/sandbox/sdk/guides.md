# How-to guides

Last updated Sep 30, 2026|Copy as Markdown| [View as Markdown](https://developers.cloudflare.com/sandbox/sdk/guides/index.md)| [Agent setup](https://developers.cloudflare.com/agent-setup/)

Note

This page documents Sandbox SDK 0.x for existing applications. For new applications, refer to [Sandboxes on Cloudflare](https://developers.cloudflare.com/sandbox/). To move an existing application to `@cloudflare/sandbox` 1.0, refer to [Migrate from Sandbox SDK 0.x](https://developers.cloudflare.com/sandbox/sdk/migrate/).

These guides show you how to solve specific problems and implement features with the Sandbox SDK. Each guide focuses on a particular task and provides practical, production-ready solutions.

[**Run background processes (Sandbox SDK 0.x)** Start and manage long-running services and applications with the Sandbox SDK 0.x.](https://developers.cloudflare.com/sandbox/sdk/guides/background-processes/)

[**Backup and restore (Sandbox SDK 0.x)** Snapshot a sandbox directory to R2 and restore it later with the Sandbox SDK 0.x.](https://developers.cloudflare.com/sandbox/sdk/guides/backup-restore/)

[**Browser terminals (Sandbox SDK 0.x)** Connect browser-based terminals to Sandbox SDK 0.x shells using xterm.js or raw WebSockets.](https://developers.cloudflare.com/sandbox/sdk/guides/browser-terminals/)

[**Use code interpreter (Sandbox SDK 0.x)** Execute Python and JavaScript code with rich outputs using the Sandbox SDK 0.x code interpreter.](https://developers.cloudflare.com/sandbox/sdk/guides/code-execution/)

[**Deploy a Sandbox application (Sandbox SDK 0.x)** Deploy a Sandbox SDK 0.x Worker and keep the npm package and container image on the same release line.](https://developers.cloudflare.com/sandbox/sdk/guides/deploy/)

[**Run Docker-in-Docker (Sandbox SDK 0.x)** Run Docker commands inside a Sandbox SDK 0.x container.](https://developers.cloudflare.com/sandbox/sdk/guides/docker-in-docker/)

[**Execute commands (Sandbox SDK 0.x)** Run commands with streaming output, error handling, and shell access in the Sandbox SDK 0.x.](https://developers.cloudflare.com/sandbox/sdk/guides/execute-commands/)

[**Expose services (Sandbox SDK 0.x)** Create preview URLs and expose ports for web services with the Sandbox SDK 0.x.](https://developers.cloudflare.com/sandbox/sdk/guides/expose-services/)

[**Watch filesystem changes (Sandbox SDK 0.x)** Monitor files and directories in real time with the Sandbox SDK 0.x to build development tools and automation workflows.](https://developers.cloudflare.com/sandbox/sdk/guides/file-watching/)

[**Work with Git (Sandbox SDK 0.x)** Clone repositories, manage branches, and automate Git operations with the Sandbox SDK 0.x.](https://developers.cloudflare.com/sandbox/sdk/guides/git-workflows/)

[**Manage files (Sandbox SDK 0.x)** Read, write, organize, and synchronize files in a sandbox with the Sandbox SDK 0.x.](https://developers.cloudflare.com/sandbox/sdk/guides/manage-files/)

[**Mount buckets (Sandbox SDK 0.x)** Mount S3-compatible object storage as local filesystems with the Sandbox SDK 0.x.](https://developers.cloudflare.com/sandbox/sdk/guides/mount-buckets/)

[**Handle outbound traffic (Sandbox SDK 0.x)** Intercept and handle outbound HTTP from Sandbox SDK 0.x sandboxes using Workers.](https://developers.cloudflare.com/sandbox/sdk/guides/outbound-traffic/)

[**Configure preview URLs on a custom domain (Sandbox SDK 0.x)** Set up wildcard DNS, routes, and TLS so Sandbox SDK 0.x exposePort preview URLs work on your domain.](https://developers.cloudflare.com/sandbox/sdk/guides/preview-urls-custom-domain/)

[**Stream output (Sandbox SDK 0.x)** Handle real-time output from commands and processes with the Sandbox SDK 0.x.](https://developers.cloudflare.com/sandbox/sdk/guides/streaming-output/)

[**WebSocket connections (Sandbox SDK 0.x)** Connect to WebSocket servers running in Sandbox SDK 0.x sandboxes.](https://developers.cloudflare.com/sandbox/sdk/guides/websocket-connections/)

[**Connect to Workers bindings (Sandbox SDK 0.x)** Access KV, R2, Durable Objects, and other bindings from a Sandbox SDK 0.x sandbox.](https://developers.cloudflare.com/sandbox/sdk/guides/workers-connections/)
