# Data Sources

DuckDB supports several data sources, including file formats, network protocols, and database systems:

* [AWS S3 buckets and storage with S3-compatible API](https://duckdb.org/docs/current/core_extensions/httpfs/s3api.html)
* [Azure Blob Storage](https://duckdb.org/docs/current/core_extensions/azure.html)
* [Blob files](https://duckdb.org/docs/current/guides/file_formats/read_file.html#read_blob)
* [Cloudflare R2](https://duckdb.org/docs/current/guides/network_cloud_storage/cloudflare_r2_import.html)
* [CSV](https://duckdb.org/docs/current/data/csv/overview.html)
* [Delta Lake](https://duckdb.org/docs/current/core_extensions/delta.html)
* [DuckLake](https://ducklake.select/)
* [Excel](https://duckdb.org/docs/current/core_extensions/excel.html)
* [httpfs](https://duckdb.org/docs/current/core_extensions/httpfs/https.html)
* [Iceberg](https://duckdb.org/docs/current/core_extensions/iceberg/overview.html)
* [JSON](https://duckdb.org/docs/current/data/json/overview.html)
* [Lance tables](https://duckdb.org/docs/current/core_extensions/lance.html)
* [MySQL](https://duckdb.org/docs/current/core_extensions/mysql.html)
* [Parquet](https://duckdb.org/docs/current/data/parquet/overview.html)
* [PostgreSQL](https://duckdb.org/docs/current/core_extensions/postgres/overview.html)
* [SQLite](https://duckdb.org/docs/current/core_extensions/sqlite.html)
* [Text files](https://duckdb.org/docs/current/guides/file_formats/read_file.html#read_text)
* [Vortex files](https://duckdb.org/docs/current/core_extensions/vortex.html)
