# Configuration

The Business Calendar has the following configuration categories: **Business Calendar**, **Layout**, **Events**, **Data**, and **Annotations**, which are specific to the plugin. The remaining categories are common to all Grafana plugins.

[](/media/docs/grafana/panels-visualizations/business-calendar/options.png)

Expand table

| Category                                                                                      | Description                                             |
|-----------------------------------------------------------------------------------------------|---------------------------------------------------------|
| [Annotations](/docs/plugins/marcusolsson-calendar-panel/latest/configuration/annotations/)    | Explains how to display and filter Grafana annotations. |
| [Business Calendar](/docs/plugins/marcusolsson-calendar-panel/latest/configuration/calendar/) | Describes the Business Calendar category options.       |
| [Events](/docs/plugins/marcusolsson-calendar-panel/latest/configuration/events/)              | Describes the Events category options.                  |
| [Layout](/docs/plugins/marcusolsson-calendar-panel/latest/configuration/layout/)              | Describes the Layout category options.                  |

## Native categories

The Business Calendar panel supports standard options, data links, value mappings, thresholds, and overrides.
