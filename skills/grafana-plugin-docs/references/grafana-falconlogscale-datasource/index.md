# Falcon LogScale data source

The CrowdStrike Falcon LogScale data source plugin allows you to query and visualize Falcon LogScale data from within Grafana.

- [Configure the Falcon LogScale data source](http://grafana-com-website.grafana-com.svc.cluster.local.:80/docs/plugins/grafana-falconlogscale-datasource/latest/configure/)
- [Falcon LogScale query editor](http://grafana-com-website.grafana-com.svc.cluster.local.:80/docs/plugins/grafana-falconlogscale-datasource/latest/editor/)
- [Falcon LogScale templates and variables](http://grafana-com-website.grafana-com.svc.cluster.local.:80/docs/plugins/grafana-falconlogscale-datasource/latest/templates-and-variables/)

## Requirements

The Falcon LogScale data source has the following requirements:

- A Falcon LogScale instance.
- Any free or paid [Grafana Cloud](http://grafana-com-website.grafana-com.svc.cluster.local.:80/pricing/) plan or an [activated on-prem Grafana Enterprise license](http://grafana-com-website.grafana-com.svc.cluster.local.:80/docs/grafana/latest/enterprise/license/activate-license/). Contracted Cloud customers should refer to their agreement.

## Compatibility requirements

There are no compatibility requirements for the Falcon LogScale data source.

## Get the most out of the Falcon LogScale data source

After installing and configuring Falcon LogScale you can:

- Add [Annotations](http://grafana-com-website.grafana-com.svc.cluster.local.:80/docs/grafana/latest/dashboards/annotations/).
- Add [Transformations](http://grafana-com-website.grafana-com.svc.cluster.local.:80/docs/grafana/latest/panels/transformations/)
- Set up [Alerting](http://grafana-com-website.grafana-com.svc.cluster.local.:80/docs/grafana/latest/alerting/)
