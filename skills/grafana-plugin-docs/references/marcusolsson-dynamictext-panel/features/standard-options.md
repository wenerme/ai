# Standard options

> Note
>
> The Business Text panel supports the **Standard options** and **Overrides** starting from version 5.0.0.

The Business Text panel supports the following standard options:

- **Unit**
- **Decimals**

[](/media/docs/grafana/panels-visualizations/business-text/panel.png)

## Overrides

You can set **Unit** and **Decimals** for a specific field or data frame using **Overrides**.

[](/media/docs/grafana/panels-visualizations/business-text/override.png)
