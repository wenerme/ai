# Zendesk data source plugin

The Zendesk data source for Grafana allows you to query and visualize data from zendesk.

> Note
>
> Grafana **Zendesk** data source plugin is currently in [public preview](/docs/release-life-cycle/). Grafana Labs offers limited support, and breaking changes might occur prior to the feature being made generally available.

## Requirements

The Zendesk data source has the following requirements:

- A Zendesk Account
- Any free or paid [Grafana Cloud](/pricing/) plan or an [activated on-prem Grafana Enterprise license](/docs/grafana/latest/enterprise/license/activate-license/). Contracted Cloud customers should refer to their agreement.
