# Timeline view

The Timeline view shows the investigation items relative to each other on a full page spread. The timeline makes it easy to see when events occurred. It also extends the data beyond the specific window to give you a broad sense of what the data was doing before and after.

[Timeline view shows items in true time scale.](/media/docs/investigations/screenshot-timeline.png)

Comments are included, so you can easily tell the complete story on a screen share.

## Edit in place

Clicking the eye icon in the top right corner of each item will expand it, so you can see the data in maximum detail as well as edit the comment right there.
