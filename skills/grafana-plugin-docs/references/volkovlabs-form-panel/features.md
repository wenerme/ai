# Features

The Business Forms panel provides an extensive set of features.

Expand table

| Section                                                                                    | Description                                                                     |
|--------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------|
| [Control panel](/docs/plugins/volkovlabs-form-panel/latest/features/control-panel/)        | Create control panels with multiple sections and the same identifier.           |
| [Custom requests](/docs/plugins/volkovlabs-form-panel/latest/features/custom-requests/)    | Create initial and update requests with custom code.                            |
| [Dynamic forms](/docs/plugins/volkovlabs-form-panel/latest/features/dynamic-forms/)        | Update form element values and options from any data source.                    |

| [Load indication](/docs/plugins/volkovlabs-form-panel/latest/features/load/)               | View how Business Forms indicates loading progress.                             |
| [Confirmation window](/docs/plugins/volkovlabs-form-panel/latest/features/confirm-window/) | Configure the confirmation window that displays before submitting form updates. |
