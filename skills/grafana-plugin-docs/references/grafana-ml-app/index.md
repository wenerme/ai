# AI and machine learning

Grafana AI combines machine learning capabilities and the latest advancements in large language models (LLMs) to help you gain actionable insights, accelerate investigations, and proactively optimize your systems with intelligent, automated tools.

* * *

## Overview

Grafana AI helps you analyze, interact with, and understand your observability data in Grafana Cloud.

Artificial intelligence tools like [Grafana Assistant](/docs/grafana-cloud/machine-learning/assistant/) and [Sift](/docs/grafana-cloud/machine-learning/sift/) deliver intelligent recommendations, automate investigations, and accelerate analysis.

Machine learning tools allow you to identify patterns, detect anomalies, and gain actionable insights.

Together, these capabilities streamline operations, reduce manual effort, and enable your teams to make faster, data-driven decisions with greater confidence.

Get started with Grafana AI on Grafana Cloud. Don’t have an account yet? [Sign up for free](/auth/sign-up/create-user/) today.
