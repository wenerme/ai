# Cost and limits for Grafana ML

Grafana ML features and capabilities (including forecasts, outlier detection, and Sift) are free to use for all Grafana Cloud accounts. Metrics generated by Grafana ML do **not** count towards billable active series for Grafana Cloud Metrics.

## Grafana ML limits

The amount of data you can train or predict on is limited in the following ways:

- 50,000 datapoints for training a series.
- 100 series per [forecast.](/docs/grafana-cloud/alerting-and-irm/machine-learning/forecasts/)
- 10 [forecasts](/docs/grafana-cloud/alerting-and-irm/machine-learning/forecasts/) per hosted Grafana instance.
- 1000 series per [outlier detector.](/docs/grafana-cloud/alerting-and-irm/machine-learning/forecasts/outlier-detection/)
- 10 [outlier detectors](/docs/grafana-cloud/alerting-and-irm/machine-learning/forecasts/outlier-detection/) per hosted Grafana instance.

To request an increase in any of these limits, [contact us](/contact?about=grafana-cloud&topic=volume-pricing&value=volume%20based%20pricing%20inquiry) or ask your account executive, support engineer, or technical account manager.
