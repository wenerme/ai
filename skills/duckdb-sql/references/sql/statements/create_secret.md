# CREATE SECRET Statement

The `CREATE SECRET` statement creates a new secret in the [Secrets Manager](https://duckdb.org/docs/current/configuration/secrets_manager.html).

## Syntax for `CREATE SECRET`

> Warning When using the [command line client](https://duckdb.org/docs/current/clients/cli/overview.html), the `CREATE SECRET` statements are stored in your DuckDB history as plain text.
